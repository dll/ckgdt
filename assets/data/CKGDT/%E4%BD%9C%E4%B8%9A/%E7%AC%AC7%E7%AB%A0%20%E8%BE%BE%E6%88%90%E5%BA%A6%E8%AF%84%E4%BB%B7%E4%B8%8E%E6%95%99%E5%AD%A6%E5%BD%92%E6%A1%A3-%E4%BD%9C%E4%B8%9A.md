## 题目一：基础题（100分）

### 题目
解释课程达成度评价的基本原理，说明达成度计算公式中各参数的含义。

### 参考答案
**达成度评价基本原理**：
达成度评价是基于OBE（成果导向教育）理念，通过量化方式评估学生对课程目标的达成程度。

**达成度计算公式**：
```
达成度(目标i) = Σ(环节得分×环节权重×目标贡献度) / Σ(环节满分×环节权重×目标贡献度)
```

**参数含义**：
- **环节得分**：学生在某教学环节的实际得分
- **环节满分**：该教学环节的满分值
- **环节权重**：该环节在总成绩中的占比
- **目标贡献度**：该环节对特定目标的贡献比例

**总达成度公式**：
```
总达成度 = Σ(目标i达成度 × 目标i权重)
```

## 题目三：思考题（100分）

### 题目
讨论基于达成度的教学归档对工程教育认证的意义，分析其在持续改进中的作用。

### 参考答案
**对工程教育认证的意义**：
1. **成果导向**：达成度评价体现OBE理念的核心要求
2. **持续改进**：为教学改进提供量化依据
3. **质量保障**：证明课程目标的达成情况
4. **国际接轨**：符合国际工程教育认证标准

**在持续改进中的作用**：
1. **问题识别**：通过达成度分析发现教学薄弱环节
2. **改进依据**：为教学方法、内容、评估的改进提供数据支持
3. **效果验证**：验证改进措施的有效性
4. **循环优化**：形成"评价-改进-再评价"的闭环
