## 四、达成度计算方法

### 4.1 单个学生达成度计算

```
目标 i 达成度 = (平时环节贡献 + 实验环节贡献 + 期末环节贡献)

其中：
平时环节贡献 = 平时得分 / 平时满分 × 目标 i 平时权重
实验环节贡献 = 实验得分 / 实验满分 × 目标 i 实验权重
期末环节贡献 = 期末得分 / 期末满分 × 目标 i 期末权重
```

### 4.2 班级达成度计算

```
班级目标 i 达成度 = Σ(学生 i 达成度) / 学生人数
```

### 4.3 达成度等级判定

| 达成度值 | 等级 | 判定 |
|----------|------|------|
| ≥ 0.70 | 优秀 | 达成 |
| ≥ 0.60 且 < 0.70 | 良好 | 达成 |
| ≥ 0.50 且 < 0.60 | 合格 | 基本达成 |
| < 0.50 | 不合格 | 未达成 |
