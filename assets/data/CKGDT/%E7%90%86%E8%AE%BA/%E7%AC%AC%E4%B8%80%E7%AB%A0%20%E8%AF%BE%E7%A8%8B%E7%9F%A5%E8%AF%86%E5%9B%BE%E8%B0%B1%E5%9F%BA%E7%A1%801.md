# 第一章 课程知识图谱基础（1）

## 教学目标
- 理解知识图谱的基本概念和在教育领域的应用
- 掌握 CKGDT 平台的系统架构和核心功能
- 了解多智能体系统在教学辅助中的作用

## 知识点

### 1.1 知识图谱概述
- 知识图谱定义：以图结构组织知识，节点表示概念，边表示关系
- 教育知识图谱：面向课程体系的知识组织方式
- 与传统目录的区别：语义关联、推理能力、可视化

### 1.2 CKGDT 平台架构
- **四层架构**：表现层 → 业务层 → 数据层 → 服务层
- **技术栈**：Flutter + SQLite + AI（DeepSeek/智谱）
- **跨平台**：Android / Windows / Web / HarmonyOS

### 1.3 多智能体系统
- 18 个专业 Agent（图谱专家、智能辅导、测验生成等）
- RAG 检索增强：基于课程内容的知识库
- 工具调用：Agent 可操作数据库、导航、生成内容

## 课堂讨论
1. 知识图谱与思维导图有什么区别？
2. 多智能体系统如何辅助个性化学习？

## 课后作业

2. 浏览课程知识图谱，记录 3 个感兴趣的知识节点
3. 思考：如何为你的专业课程构建知识图谱？
