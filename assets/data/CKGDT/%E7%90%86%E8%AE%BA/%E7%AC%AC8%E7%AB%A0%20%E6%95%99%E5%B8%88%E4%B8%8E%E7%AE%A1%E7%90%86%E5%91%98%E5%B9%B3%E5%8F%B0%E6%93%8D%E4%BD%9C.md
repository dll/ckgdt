| 项目 | 内容 |

| **课程名称** | 课程知识图谱与数字孪生平台（CKGDT） |

---

## 一、教学目标

1. 熟悉教师端工作台的22项工具功能，能够高效完成日常教学管理。
2. 掌握教学管理模块（大纲/教案/进度/班级/题库/通知）的操作方法。
3. 了解管理员端的账号管理、数据导入导出、仓库分析等高级功能。
4. 理解数据同步机制（Gitee双向同步、task_id重映射）和角色权限模型。

## 四、教学过程

### 第1课时（理论讲授，2学时，90分钟）

#### 1. 导入环节（5-10分钟）

展示一个场景："学期初，教师需要准备什么？学期中需要管理什么？学期末需要归档什么？"通过教学全周期引入教师端工具的必要性。

#### 2. 新课讲授（50-55分钟）

**（1）教师端工作台（15分钟）**

22项工具分类：

| 类别 | 工具 | 数量 |
|------|------|------|
| 教学准备 | 大纲编辑、教案编写、资源上传 | 5项 |
| 课堂教学 | 签到管理、课堂消息、实时互动 | 4项 |
| 作业管理 | 实验发布、作业批阅、成绩录入 | 5项 |
| 评价分析 | 考核管理、达成度分析、试卷分析 | 4项 |
| 学生管理 | 班级管理、学情查看、预警处理 | 4项 |

教学中心：
- 教学大纲管理：编写、修改、版本控制
- 教案管理：按课时编写教案、关联资源
- 教学进度：计划 vs 实际进度对比
- 资源管理：上传、分类、关联图谱节点

评价中心：
- 成绩管理：录入、修改、统计、导出
- 达成度分析：三维成绩、章节达成度、知识点达成度
- 试卷分析：难度、区分度、成绩分布
- 持续改进：基于数据的教学调整建议

**（2）教学管理模块（15分钟）**

大纲管理：
- 课程信息：名称、学时、学分、先修课程
- 章节设置：标题、学时分配、教学目标
- 成绩构成：平时/实验/考核比例

教案管理：
- 按课时编写：教学目标、内容、方法、时间分配
- 关联资源：绑定视频、文档、图谱节点
- 教学反思：课后记录教学效果

班级管理：
- 班级创建：名称、学年、课程关联
- 成员管理：添加/移除学生、分组
- 权限设置：助教权限、学生权限

题库管理：
- 题目录入：四选一题型、章节关联
- 题目分类：按章节、难度、知识点
- 组卷功能：手动选题/自动组卷

通知管理：
- 发布通知：标题、内容、接收范围
- 通知模板：系统通知、成绩通知、预警通知
- 未读追踪：已读/未读状态统计

**（3）管理员功能（10分钟）**

账号管理：
- 用户CRUD：创建、查询、修改、禁用
- 角色分配：学生/教师/管理员
- 批量导入：Excel导入学生名单

数据导入导出：
- 导入：成绩Excel、实验数据、图谱JSON
- 导出：成绩表、分析报告、归档文档
- 格式支持：XLSX、JSON、CSV

仓库分析：
- Gitee仓库使用统计
- 学生提交频率分析
- 代码质量评估

AI额度管理：
- API调用统计
- 额度分配与监控
- 成本控制策略

**（4）数据同步与权限（10分钟）**

Gitee双向同步：
- 学生端 → 教师端：提交数据自动同步
- 教师端 → 学生端：成绩、反馈同步
- 同步机制：JSON文件 + Gitee API

task_id重映射：
- 问题：不同设备的自增ID不同
- 解决：通过title自然键匹配后重映射
- 流程：提取原始ID → 按title查找 → 映射新ID → 更新引用

角色权限模型：

| 角色 | 权限 |
|------|------|
| 学生 | 学习、提交、查看个人数据 |
| 教师 | 教学管理、成绩管理、查看班级数据 |
| 管理员 | 全部功能、系统配置、用户管理 |

#### 3. 课堂练习（10分钟）

请学生列出作为教师最常用的5个工具，并说明使用频率高的原因。

#### 4. 小结与作业布置（5分钟）

**小结**：教师端覆盖教学全周期，管理员端负责系统运维，权限模型保证数据安全。

**作业**：
- 熟悉教师端工作台的22项工具
- 思考：如何设计一个高效的学期初准备工作清单？
- 准备实验：以教师身份完成一个完整的教学管理流程

### 第2课时（实验操作，2学时，90分钟）

#### 1. 导入环节（5分钟）

回顾教师端和管理员端功能架构，介绍本节课实验目标：以教师和管理员身份完成平台操作。

#### 2. 新课讲授（25-30分钟）

**（1）平台部署概述（10分钟）**

CKGDT支持4端部署：
- Android：APK安装
- Windows：EXE运行
- Web：浏览器访问
- HarmonyOS：HAP安装

多智能体系统：
- 18个专业智能体
- AgentRegistry注册表管理
- BaseAgent基类：会话管理、AI调用、工具执行

**（2）数据同步详解（10分钟）**

同步流程：
```
学生提交 → 写入本地DB → 同步到Gitee仓库
教师拉取 → 读取Gitee数据 → 合并到本地DB
```

冲突处理：
- 最后写入优先（Last Write Wins）
- 批改数据保护：已评分记录不被覆盖
- SHA去重：内容无变化则跳过commit

**（3）实验任务说明（10分钟）**
- 实验8-1：以教师身份创建一个新课程
- 实验8-2：编写课程大纲和教案
- 实验8-3：发布一个通知
- 实验8-4：以管理员身份导入学生名单

#### 3. 平台演示（10分钟）

演示教师端和管理员端操作：
- 以教师身份登录 → 创建课程 → 编写大纲
- 创建教案 → 关联资源
- 发布通知 → 选择接收范围
- 以管理员身份登录 → 导入学生名单 → 分配角色

#### 4. 课堂练习（40-45分钟）

1. 以教师身份创建一个课程，填写基本信息（10分钟）
2. 编写课程大纲，设置章节和学时（10分钟）
3. 创建一个教案，关联图谱节点（10分钟）
4. 以管理员身份导入一个学生名单（10分钟）

教师巡回指导，解答操作问题。

#### 5. 小结与作业布置（5分钟）

**小结**：本章完整学习了教师端和管理员端的平台操作，掌握了教学管理全流程。

**作业**：
- 完成一个完整的学期教学管理流程（创建课程→编写大纲→发布任务→录入成绩→生成报告）
- 整理CKGDT平台的使用心得，形成一份"新教师入门指南"
- 总结本课程的学习收获，完成课程总结报告

## 五、课程思政融入点

1. **责任意识**：教师端工具的设计体现了教育工作者对教学质量的责任担当。
2. **规范管理**：权限模型和数据同步机制保证了教学数据的安全性和规范性。
3. **技术赋能**：平台通过技术手段减轻教师重复性工作，让教师有更多精力关注学生发展。
