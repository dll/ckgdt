# 第5章 智能学习路径与学习分析

| 项目 | 内容 |
|------|------|
| **课程名称** | 课程知识图谱与数字孪生平台（CKGDT） |
| **章节** | 第5章 智能学习路径与学习分析 |
| **课时** | 4学时（理论2学时 + 实验2学时） |
| **课程目标** | 目标3：掌握智能学习路径规划与学习分析技术 |

---

## 一、教学目标

1. 理解学习分析的定义、技术框架及其在个性化学习中的价值。
2. 掌握知识掌握度分析方法，能够计算节点达成度并解读分析结果。
3. 能够运用前置关系路径生成算法规划学习路径，理解RAG检索增强的推荐机制。
4. 能够解读学习仪表盘数据，进行薄弱知识点诊断和学习预警。

---

## 二、教学重点与难点

| 类型 | 内容 |
|------|------|
| **重点** | 知识掌握度分析：节点达成度计算方法 |
| **重点** | 学习路径规划：前置关系路径生成算法 |
| **重点** | RAG检索增强的个性化推荐机制 |
| **难点** | 多维学习数据的综合分析与决策 |
| **难点** | 学习预警模型的风险等级判定算法 |

---

## 三、教学方法

- **讲授法**：学习分析理论、路径规划算法
- **演示法**：CKGDT学习分析仪表盘、路径推荐演示
- **案例法**：以具体学生数据展示路径推荐效果
- **实操法**：学生查看分析数据、体验路径推荐
- **讨论法**：学习分析数据的教学应用价值

## 四、教学过程

### 第1课时（理论讲授，2学时，90分钟）

#### 1. 导入环节（5-10分钟）

展示场景："一名学生在第3章测验中错了一道关于'递归'的题，系统应该推荐他学什么？"引出学习路径推荐的核心问题——如何基于知识图谱和学习数据做出个性化推荐。

#### 2. 新课讲授（50-55分钟）

**（1）学习分析概述（10分钟）**
- 定义：收集、分析和报告关于学习者及其学习环境的数据，以理解和优化学习
- 技术框架：数据采集 → 数据处理 → 分析建模 → 可视化呈现 → 教学决策
- CKGDT的学习分析：整合图谱、测验、行为、时间等多维数据

**（2）知识掌握度分析（15分钟）**

节点达成度计算：
```
节点达成度 = f(直接学习, 关联学习, 测验验证, 时间投入)
```

计算维度：
- 直接学习：该节点的学习时长、资源消费
- 关联学习：相邻节点的学习情况
- 测验验证：相关测验题的正确率
- 时间投入：学习时间与推荐时间的比值

达成度等级：
- 0-20%：未入门（红色）
- 20-50%：初步了解（橙色）
- 50-75%：基本掌握（黄色）
- 75-90%：熟练掌握（绿色）
- 90-100%：精通（深绿色）

**（3）学习路径规划（15分钟）**

前置关系路径生成：
1. 确定目标节点（学生想学的概念）
2. 从知识图谱中提取所有前置依赖关系
3. 按拓扑排序生成学习顺序
4. 结合已学状态跳过已掌握节点
5. 生成个性化学习路径

学习链路可视化：
- 已学节点（绿色）→ 在学节点（黄色）→ 待学节点（灰色）
- 路径长度估计、时间预估

**（4）个性化推荐与RAG（10分钟）**

RAG检索增强推荐：
- 知识库：课程内容文档、视频、习题
- 检索：基于学生当前状态检索相关资源
- 增强：结合图谱关系和学习历史进行排序
- 推荐：返回最匹配的学习资源列表

资源匹配策略：
- 补缺型推荐：针对薄弱知识点
- 拓展型推荐：针对已掌握知识点的深化
- 预习型推荐：针对即将学习的前置内容

#### 3. 课堂练习（10分钟）

请学生分析：如果一名学生在"函数"和"循环"两个概念的测验中都错了，学习路径推荐系统应该如何决策？

#### 4. 小结与作业布置（5分钟）

**小结**：学习分析通过多维数据计算知识掌握度，基于图谱关系生成个性化学习路径，RAG增强推荐相关资源。

**作业**：
- 手动计算一个简单图谱中某节点的达成度（假设数据）
- 分析学习路径规划中拓扑排序的必要性
- 预习第6章：实验实践与作品评价

---

### 第2课时（实验操作，2学时，90分钟）

#### 1. 导入环节（5分钟）

回顾学习分析的核心概念和路径规划算法，介绍本节课实验目标：查看学习分析数据，体验智能路径推荐。

#### 2. 新课讲授（25-30分钟）

**（1）学习仪表盘详解（10分钟）**
- 5维雷达图：知识掌握、学习时长、测验成绩、实验完成、作品贡献
- 活跃热力图：30天学习频率的可视化（GitHub风格）
- 成长曲线：学习进度的时序折线图

**（2）学习预警机制（10分钟）**
- 风险等级判定：
  - 绿色（正常）：综合风险分 < 30
  - 黄色（关注）：30 ≤ 综合风险分 < 60
  - 红色（预警）：综合风险分 ≥ 60
- 薄弱知识点诊断：基于测验错题和达成度数据
- 预警触发条件：连续缺席、成绩骤降、活跃度下降

**（3）实验任务说明（10分钟）**
- 实验5-1：查看自己的学习分析仪表盘
- 实验5-2：分析雷达图数据，识别薄弱维度
- 实验5-3：查看活跃热力图，分析学习规律
- 实验5-4：体验AI学习路径推荐功能

#### 3. 平台演示（10分钟）

演示学习分析与路径推荐流程：
- 进入学习中心 → 查看5维雷达图
- 切换到活跃热力图 → 查看30天学习频率
- 进入图谱 → 选择一个未掌握节点 → 触发路径推荐
- 查看推荐的学习路径和资源列表

#### 4. 课堂练习（40-45分钟）

1. 查看自己的学习分析仪表盘，截图保存（10分钟）
2. 分析雷达图数据，写一段50字的自我评估（10分钟）
3. 查看活跃热力图，总结自己的学习时间规律（10分钟）
4. 使用AI路径推荐功能，获取一个章节的学习计划（10分钟）

教师巡回指导，帮助学生理解数据含义。

#### 5. 小结与作业布置（5分钟）

**小结**：本章学习了学习分析的核心技术和CKGDT平台的学习仪表盘、路径推荐功能。

**作业**：
- 基于自己的学习分析数据，写一份200字的"学习诊断报告"
- 为一位"假设的薄弱学生"设计学习干预方案
- 思考：学习分析数据如何支撑第6章的"实验评价"？
- 预习第6章：实验实践与作品评价

## 五、课程思政融入点

1. **因材施教**：智能学习路径体现了孔子"因材施教"的教育理念，技术赋能个性化教育。
2. **数据驱动决策**：培养教师基于数据而非经验做教学决策的科学思维。
3. **学习者中心**：路径推荐尊重学生的个体差异，体现"以学生为中心"的教育理念。
