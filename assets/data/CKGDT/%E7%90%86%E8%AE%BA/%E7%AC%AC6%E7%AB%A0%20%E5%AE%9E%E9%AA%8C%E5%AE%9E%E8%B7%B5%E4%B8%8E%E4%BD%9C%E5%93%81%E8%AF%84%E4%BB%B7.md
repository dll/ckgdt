| 项目 | 内容 |
|------|------|
| **课程名称** | 课程知识图谱与数字孪生平台（CKGDT） |
| **章节** | 第6章 实验实践与作品评价 |
| **课时** | 4学时（理论2学时 + 实验2学时） |
| **课程目标** | 目标4：掌握实验管理、作品评价和项目考核的平台操作方法 |

---

## 一、教学目标

1. 理解CKGDT实验管理的完整流程，包括任务发布、学生提交和AI自动批阅。
2. 掌握实验报告模板的命名规范和学生作品的5维评分体系。
3. 能够运用项目考核模块进行分组管理、答辩评审和成绩统计。
4. 理解协作开发中的Git仓库管理和GradingAgent三类批阅机制。

---

## 三、教学方法

- **讲授法**：实验管理流程、评分体系设计
- **演示法**：实验任务发布、提交、批阅全流程
- **案例法**：展示真实的学生实验报告和作品评分

## 四、教学过程

### 第1课时（理论讲授，2学时，90分钟）

#### 1. 导入环节（5-10分钟）

提出问题："一个班级40名学生，每次实验提交40份报告，教师需要多少时间批阅？如果用AI辅助呢？"通过实际教学痛点引入实验管理和AI批阅的必要性。

#### 2. 新课讲授（50-55分钟）

**（1）实验管理流程（15分钟）**

完整流程：
```
教师发布任务 → 学生领取任务 → 学生完成实验 → 提交代码/报告
    → AI自动批阅（初评） → 教师复核（终评） → 成绩记录
```

LabTaskDao核心功能：
- 任务CRUD：创建、查询、更新、删除实验任务
- 提交管理：接收学生提交、存储代码和报告
- 批阅管理：AI初评 + 教师终评

**（2）实验报告模板（10分钟）**

命名规范：
```
{学号}_{实验编号}_{实验名称}.md
例：419116_01_知识图谱构建.md
```

报告结构：
- 实验目的
- 实验环境
- 实验步骤（含截图）
- 实验结果
- 问题与解决方案
- 心得体会

**（3）学生作品评价体系（15分钟）**

5维评分体系：

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 创意性 | 25% | 问题定义的独特性、解决方案的创新性 |
| 实现度 | 30% | 功能完整性、代码质量、技术难度 |
| 文档 | 15% | 文档完整性、表述清晰度、规范性 |
| 演示 | 15% | 展示效果、表达能力、问答表现 |
| 协作 | 15% | 团队贡献、代码审查、知识分享 |

匿名机制：评分时隐藏学生身份，避免偏见。

排行榜：按综合得分排名，激励学生竞争。

**（4）项目考核与协作（15分钟）**

项目考核模块：
- 分组管理：自动/手动分组、组员调配
- 答辩管理：答辩日程、评分表、评语
- 贡献度评估：Git提交记录、代码审查参与度
- 成绩统计：加权平均、分布分析

协作开发：
- Git仓库：每组一个仓库，支持分支管理
- 代码审查：Pull Request + 教师/同伴评审
- 分支策略：main（稳定）→ feature/*（开发）→ merge（合并）

#### 3. 课堂练习（10分钟）

请学生思考：5维评分体系中，哪个维度最难量化？为什么？

#### 4. 小结与作业布置（5分钟）

**小结**：CKGDT提供了从实验发布到成绩统计的完整闭环，AI批阅大幅减轻教师负担。

**作业**：
- 设计一个自己课程的实验任务（含任务描述、评分标准、截止时间）
- 分析5维评分体系的合理性，提出改进建议
- 预习第7章：达成度评价与教学归档

---

### 第2课时（实验操作，2学时，90分钟）

#### 1. 导入环节（5分钟）

回顾实验管理和作品评价的核心概念，介绍本节课实验目标：体验实验发布、提交、AI批阅全流程。

#### 2. 新课讲授（25-30分钟）

**（1）GradingAgent三类批阅（10分钟）**

- 实验批阅（LabGradingAgent）：代码质量、功能完成度、报告规范性
- 考核批阅（AssessmentGradingAgent）：项目完成度、创新性、答辩表现
- 作品批阅（WorksGradingAgent）：创意、实现、文档、演示、协作

AI批阅流程：
1. 接收提交内容（代码/报告/作品）
2. 分析内容质量（语法、逻辑、完整性）
3. 对照评分标准打分
4. 生成详细评语和改进建议
5. 返回初评结果供教师复核

**（2）实验任务发布（10分钟）**
- 任务标题、描述、目标
- 截止时间、评分标准
- 参考资料、示例代码
- 关联知识图谱节点

**（3）实验任务说明（10分钟）**
- 实验6-1：发布一个实验任务
- 实验6-2：以学生身份提交一份实验报告
- 实验6-3：使用AI批阅功能进行初评
- 实验6-4：查看批阅结果和评语

#### 3. 平台演示（10分钟）

演示实验管理全流程：
- 进入教师端 → 实验管理 → 创建新任务
- 填写任务信息 → 设置评分标准 → 发布任务
- 切换到学生端 → 查看任务 → 提交报告
- 切换到教师端 → 查看提交 → 使用AI批阅 → 查看评分

#### 4. 课堂练习（40-45分钟）

1. 创建一个实验任务（10分钟）
2. 以学生身份提交一份简单报告（10分钟）
3. 使用AI批阅功能进行初评（10分钟）
4. 查看批阅结果，调整最终评分（10分钟）

教师巡回指导，解答操作问题。

#### 5. 小结与作业布置（5分钟）

**小结**：本章学习了实验管理、作品评价和项目考核的完整流程，体验了AI辅助批阅。

**作业**：
- 完成一个完整的实验管理流程（发布→提交→批阅→统计）
- 设计一个适用于自己课程的5维评分量规
- 思考：AI批阅结果如何纳入第7章的"达成度评价"？
- 预习第7章：达成度评价与教学归档

## 五、课程思政融入点

1. **工程伦理**：实验和作品评价应公正、透明，培养学生的学术诚信意识。
2. **团队协作**：项目考核中的协作评分引导学生学会团队合作和知识分享。
3. **创新驱动**：创意性评分维度鼓励学生突破常规，培养创新精神。
