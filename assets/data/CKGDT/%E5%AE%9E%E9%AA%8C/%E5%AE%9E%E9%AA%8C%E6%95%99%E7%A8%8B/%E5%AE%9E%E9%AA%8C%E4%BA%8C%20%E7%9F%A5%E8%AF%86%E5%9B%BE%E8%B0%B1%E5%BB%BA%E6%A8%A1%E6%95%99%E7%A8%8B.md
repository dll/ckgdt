# 实验二：知识图谱建模

## 实验目标
掌握使用 PlantUML 和平台内置工具创建课程知识图谱的方法。

## 核心任务
1. 分析课程章节结构，提取核心概念
2. 定义概念间的语义关系
3. 使用 PlantUML 绘制图谱
4. 导入平台并验证可视化效果

## 操作指南

### 1. 概念提取
- 阅读课程大纲，识别核心知识点
- 为每个概念定义：名称、类型（core/advanced/basic）、难度（1-5）
- 建立概念卡片列表

### 2. 关系定义
- **包含关系**（part_of）：章节包含知识点
- **前置关系**（prerequisite）：学习依赖
- **相关关系**（related_to）：语义关联
- 为每条关系添加权重（0-1）和描述

### 3. PlantUML 绘制
```plantuml
@startuml
topic "课程知识图谱" as root {
  topic "第1章" as ch1 {
    topic "概念A" as a
    topic "概念B" as b
  }
  topic "第2章" as ch2 {
    topic "概念C" as c
  }
}
a --> b : 包含
b --> c : 前置
@enduml
```

### 4. 平台导入
- 将 PlantUML 代码保存为 .puml 文件
- 在"素材中心"上传并预览
- 在"图谱"页面查看渲染效果
