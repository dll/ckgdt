# 平台技术栈参考文档

## 目录说明

本目录存放 CKGDT 平台技术栈相关参考文档，辅助课程知识图谱、数字孪生、学习分析、达成评价与教学归档实验。

## 内容范围

| 类别 | 文档内容 | 说明 |
|------|----------|------|
| 知识图谱工具 | PlantUML、Neo4j、Protégé、OWL、RDF | 图谱建模与可视化工具 |
| 数字孪生平台 | 学习者画像建模、行为仿真、风险预警 | 数字孪生教学场景工具 |
| 学习分析工具 | 学习分析仪表盘、数据可视化、学习路径规划 | 学习数据分析工具 |
| AI辅助教学 | 多智能体系统、RAG检索增强、AI批阅 | AI赋能教学工具 |
| 教学管理平台 | CKGDT平台操作、课程配置、班级管理 | 平台使用参考 |
| 数据同步工具 | Gitee仓库管理、JSON同步、Git协作 | 数据同步与版本管理 |
