## UML 参考资料

| UML 图类型 | 用途 | 适用场景 |
|------------|------|----------|
| 用例图 | 描述系统功能与参与者关系 | 需求分析阶段 |
| 类图 | 描述系统类结构及关系 | 系统设计阶段 |
| 序列图 | 描述对象间交互时序 | 功能实现阶段 |
| 活动图 | 描述业务流程或算法逻辑 | 流程分析阶段 |
| 状态图 | 描述对象状态转换 | 状态管理设计 |
| 组件图 | 描述系统组件及依赖 | 架构设计阶段 |
| 部署图 | 描述系统物理部署 | 部署运维阶段 |
