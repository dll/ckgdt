# 智慧课程审核清单

## 一、资源完整度

| 检查项 | 要求 | 状态 |
| --- | --- | --- |
| 教学大纲 | 明确课程目标、章节、评价方式 | 待审核 |
| 教学进度 | 与章节、实验、作业、考核对应 | 待审核 |
| 理论资源 | 每章有教案、测验、作业 | 待审核 |
| 实验资源 | 有实验教程、报告模板、评分要求 | 待审核 |
| 归档资源 | 期初、期中、期末、结课材料齐全 | 待审核 |

## 二、知识图谱

| 检查项 | 要求 | 状态 |
| --- | --- | --- |
| 课程图谱 | 覆盖课程目标、章节和核心知识点 | 待审核 |
| 节点属性 | 节点有类型、难度、权重或目标映射 | 待审核 |
| 关系类型 | 包含前置、包含、相关、支撑等关系 | 待审核 |
| 学习路径 | 能根据图谱给出学习建议 | 待审核 |

## 三、数字孪生

| 检查项 | 要求 | 状态 |
| --- | --- | --- |
| 学生画像 | 能体现掌握度、活跃度、任务完成度 | 待审核 |
| 教师画像 | 能体现教学覆盖、反馈、班级健康度 | 待审核 |
| AI 解读 | 能给出可执行建议 | 待审核 |
| 人体隐喻 | 图谱节点、连接、健康状态表达清晰 | 待审核 |

## 四、评价闭环

| 检查项 | 要求 | 状态 |
| --- | --- | --- |
| 测验 | 支撑章节知识检测 | 待审核 |
| 作业 | 支撑基础、实践、思考能力评价 | 待审核 |
| 实验 | 支撑实践能力评价 | 待审核 |
| 试卷分析 | 能分析课程目标达成 | 待审核 |
| 达成报告 | 能形成持续改进建议 | 待审核 |

## 五、平台化

| 检查项 | 要求 | 状态 |
| --- | --- | --- |
| 资源包清单 | 一键生课后列出所有资源 | 待审核 |
| 课程迁移 | MAD、SEB 等课程可复用模板 | 待审核 |
| 可编辑 | 生成后可修改、补充、增强 | 待审核 |
| 可归档 | 支持预览、打印、归档 | 待审核 |
