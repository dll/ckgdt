**适用场景**：

## 附录：智能体匹配机制

### matchScore 算法

```
1. 当前有活跃智能体且匹配度 > 0.5 → 继续使用
2. 遍历所有智能体，取 matchScore 最高的
3. 最高分 < 0.3 → 使用 assistant 兜底
```

**匹配分数计算**：
- 基础分：关键词匹配（匹配1个=0.4，2个=0.6，3+个=0.8）
- 上下文加分：当前会话已激活此智能体 → +0.3
- 总分 clamp 到 [0.0, 1.0]

### 多智能体编排（OrchestratorAgent）

当一个任务需要多个Agent协同时，使用链式编排：
```dart
OrchestratorAgent().runChain(
  agentChain: ['safety', 'grading', 'ethics'],  // 安全审查 → 批阅 → 伦理评审
);
```

每个Agent的回复作为下一个Agent的输入，通过 Zone 注入 chainId 实现日志追踪。
