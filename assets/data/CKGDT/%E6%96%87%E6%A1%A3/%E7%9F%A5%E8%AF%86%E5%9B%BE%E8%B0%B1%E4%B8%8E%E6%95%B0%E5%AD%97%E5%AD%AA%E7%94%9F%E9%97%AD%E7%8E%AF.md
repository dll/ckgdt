# 知识图谱与数字孪生闭环

## 闭环模型

课程知识图谱回答“学什么、先学什么、关联什么”，数字孪生回答“谁在学、学得怎样、下一步怎么干预”。两者共同形成智慧课程的核心闭环。

```text
课程目标
  -> 知识节点
  -> 资源与活动
  -> 学习行为数据
  -> 师生数字孪生
  -> 风险诊断与学习推荐
  -> 教学干预
  -> 达成评价
  -> 图谱与资源持续改进
```

## 从图谱到人体隐喻

| 图谱元素 | 数字孪生隐喻 | 教学含义 |
| --- | --- | --- |
| 核心节点 | 器官 | 关键知识或核心能力 |
| 前置关系 | 血管/神经 | 学习依赖和认知通路 |
| 节点掌握度 | 健康指标 | 学生对知识点的掌握情况 |
| 薄弱节点 | 风险部位 | 需要补救的知识点或能力 |
| 学习路径 | 康复/训练方案 | 个性化学习建议 |
| 教学干预 | 治疗/调节 | 教师的讲解、反馈、资源推送 |

## 学生画像

- **知识健康度**：概念覆盖率、薄弱节点数、前置关系断点。
- **学习活跃度**：登录、学习、测验、作业、实验提交行为。
- **任务完成度**：章节测验、作业、实验和项目完成情况。
- **风险预警**：低掌握节点、低提交率、连续低分任务。
- **推荐行动**：复习节点、补做任务、观看视频、参与实验。

## 教师画像

- **教学覆盖度**：大纲、进度、资源、活动与目标的覆盖情况。
- **评价反馈度**：测验、作业、实验、作品、试卷分析的反馈闭环。
- **班级健康度**：班级整体掌握度、风险学生比例、薄弱章节分布。
- **资源建设度**：课程包完整度、案例演示、实验教程、归档材料。
- **改进建议**：调整教学节奏、补充资源、加强反馈、优化评价设计。

## 平台落地

1. 图谱页面展示节点和关系。
2. 数字孪生页面展示师生画像与 AI 解读。
3. 学习路径根据薄弱节点推荐资源。
4. 作业、实验、测验和试卷分析回写达成数据。
5. 达成与归档模块形成可审核材料。
