### 幻灯片2：本章目录

- **标题**：本章内容概览
- **要点**：
  - 实验管理与提交流程
  - 实验报告模板
  - 作品展示与评分体系
  - 项目考核与答辩

- **备注**：本章实践性强，建议边讲边做。

### 幻灯片3：实验管理体系

- **标题**：CKGDT实验管理架构
- **要点**：
  - 实验任务定义：lab_tasks表（标题、描述、截止时间）
  - 实验提交：lab_submissions表（文件路径、提交时间）
  - 实验报告：student_reports表（报告内容、评分）
  - DAO层：lab_task_dao.dart封装所有操作
  - 流程：教师发布→学生提交→AI批阅→教师确认
- **配图建议**：实验管理流程图 + 数据表关系图
- **备注**：实验管理是"教学做评"一体化的关键环节。

### 幻灯片4：实验提交流程

- **标题**：学生实验提交全流程
- **要点**：
  - 步骤1：学生查看实验任务要求
  - 步骤2：完成实验并准备提交材料
  - 步骤3：通过平台提交（文件上传）
  - 步骤4：系统自动触发同步到Gitee仓库
  - 步骤5：查看提交状态和批阅结果
  - 关键点：即时同步、SHA去重、批改数据保护
- **配图建议**：学生提交流程图 + 界面截图
- **备注**：提交后立即同步，不等定时器，确保数据实时性。

### 幻灯片5：实验报告规范

- **标题**：实验报告模板与规范
- **要点**：
  - 报告模板：report_templates表预定义结构
  - 报告内容：实验目的、步骤、结果、分析、心得
  - 命名规范：学号_实验名_日期.md
  - 提交格式：Markdown或PDF
  - 评分维度：完成度、正确性、创新性、文档质量
- **配图建议**：报告模板示例 + 评分维度说明
- **备注**：规范的报告是实验教学的重要产出。

### 幻灯片6：作品展示体系

- **标题**：学生作品展示平台
- **要点**：
  - 作品类型：课程项目、实验成果、创新作品
  - 展示功能：上传、预览、下载、分享
  - 5维评分：创新性、实用性、技术性、美观度、文档质量
  - 排行榜：按总分排序，激发竞争
  - 匿名机制：评审过程匿名，保证公平
- **配图建议**：作品展示界面 + 5维评分雷达图
- **备注**：作品展示是学生"学以致用"的最佳体现。

### 幻灯片7：5维评分体系详解

- **标题**：如何科学评价学生作品？
- **要点**：
  - 创新性（20%）：是否有独特的思路或方法
  - 实用性（25%）：是否解决了实际问题
  - 技术性（25%）：技术实现的难度和质量
  - 美观度（15%）：界面设计和用户体验
  - 文档质量（15%）：文档的完整性和可读性
  - 评分方式：教师评分 + 同学互评 + AI辅助
- **配图建议**：5维评分标准表 + 评分示例
- **备注**：5维评分比单一分数更全面、更公平。

### 幻灯片8：作品互动功能

- **标题**：让作品"活"起来
- **要点**：
  - 点赞功能：一键点赞，表达认可
  - 评论功能：发表评论，交流想法
  - 浏览统计：查看作品的浏览量
  - 收藏功能：收藏优秀作品
  - 分享功能：生成分享链接
- **配图建议**：互动功能界面截图 + 互动数据统计
- **备注**：互动功能促进同伴学习和交流。

### 幻灯片9：项目考核管理

- **标题**：项目考核的组织与管理
- **要点**：
  - 考核分组：assessment_groups表（分组信息）
  - 项目定义：assessment_projects表（项目要求）
  - 答辩安排：defense_records表（答辩时间、评委）
  - 贡献度评估：团队成员的实际工作量
  - 成绩统计：项目得分+答辩表现+贡献度
- **配图建议**：项目考核流程图 + 分组管理界面
- **备注**：项目考核是综合能力的全面检验。

### 幻灯片10：答辩管理

- **标题**：答辩流程设计
- **要点**：
  - 答辩准备：PPT制作、演示脚本
  - 答辩流程：自述（10分钟）→提问（10分钟）→评分
  - 评委评分：多维度评分表
  - 答辩记录：defense_records表存储
  - 成绩计算：去掉最高最低分取平均
- **配图建议**：答辩流程图 + 评分表模板
- **备注**：答辩不仅考察技术能力，还考察表达和沟通能力。

### 幻灯片11：贡献度评估

- **标题**：公平评估团队贡献
- **要点**：
  - 贡献度定义：团队成员在项目中的实际工作量
  - 评估方法：Git提交分析 + 互评 + 教师评价
  - Git分析：代码提交量、代码质量、协作频率
  - 互评机制：团队成员互相评分
  - 贡献度系数：贡献度×团队得分=个人得分
- **配图建议**：贡献度评估方法图 + Git分析示例
- **备注**：贡献度评估解决"搭便车"问题。

### 幻灯片12：协作开发与Git

- **标题**：用Git管理团队项目
- **要点**：
  - Git仓库：每个团队一个Gitee仓库
  - 分支策略：main（稳定）+ develop（开发）+ feature（功能）
  - 代码审查：Pull Request + Code Review
  - 提交规范：conventional commits（feat/fix/docs）
  - CI/CD：自动化测试和构建
- **配图建议**：Git分支策略图 + PR流程图
- **备注**：Git协作是现代软件开发的必备技能。

### 幻灯片13：AI辅助批阅概述

- **标题**：AI赋能批阅效率
- **要点**：
  - 三类GradingAgent：
    - lab_grading_agent：实验报告批阅
    - assessment_grading_agent：项目考核批阅
    - works_grading_agent：作品批阅
  - 批阅维度：完成度、正确性、创新性、规范性
  - 输出：评分+详细反馈+改进建议
  - 教师角色：AI初步评分→教师审核确认
- **配图建议**：AI批阅架构图 + 三类Agent关系
- **备注**：AI批阅不是替代教师，而是提高效率。

### 幻灯片14：实验报告AI批阅

- **标题**：lab_grading_agent工作原理
- **要点**：
  - 输入：学生实验报告 + 实验要求
  - 分析：内容完整性、步骤正确性、结果准确性
  - 评分：按维度打分（满分100）
  - 反馈：详细评语 + 改进建议
  - 输出：评分结果 + 评语 → lab_submissions表
- **配图建议**：AI批阅流程图 + 输出结果示例
- **备注**：AI批阅结果需要教师审核，确保公平性。

### 幻灯片15：作品AI批阅

- **标题**：works_grading_agent工作原理
- **要点**：
  - 输入：学生作品 + 5维评分标准
  - 分析：创新性、实用性、技术性、美观度、文档质量
  - 评分：5维度分别打分
  - 反馈：各维度详细评语
  - 输出：5维评分 + 综合评语 → student_works表
- **配图建议**：作品AI批阅流程图 + 5维评分示例
- **备注**：作品批阅比实验报告更复杂，需要更多维度的评估。

### 幻灯片16：实践任务——设计评分标准

- **标题**：课堂实践：设计作品评分标准
- **要点**：
  - 任务：为一个 CKGDT 课程图谱项目设计5维评分标准
  - 步骤1：确定5个评分维度（10分钟）
  - 步骤2：为每个维度定义评分等级（10分钟）
  - 步骤3：设计AI批阅的提示词（10分钟）
  - 步骤4：小组互评，优化评分标准（10分钟）
  - 时间：40分钟
- **配图建议**：实践任务清单 + 评分标准模板
- **备注**：让学生体验评分标准设计的过程。

### 幻灯片17：本章小结

- **标题**：本章知识回顾
- **要点**：
  - 实验管理：lab_tasks→lab_submissions→批阅
  - 作品展示：5维评分+排行榜+互动
  - 项目考核：分组+答辩+贡献度
  - 协作开发：Git仓库+分支+代码审查
  - AI批阅：三类GradingAgent+教师审核
- **配图建议**：思维导图总结本章要点
- **备注**：实验和作品是"教学做评"的完整闭环。
