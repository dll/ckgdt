### 幻灯片3：OBE理念概述

- **标题**：什么是OBE（成果导向教育）？
- **要点**：
  - 定义：以学生学习成果为导向的教育理念
  - 核心原则：以学生为中心、成果导向、持续改进
  - 起源：美国工程教育认证（ABET）
  - 中国实践：工程教育专业认证
  - OBE四要素：定义成果→设计课程→评价达成→持续改进
- **配图建议**：OBE理念框架图 + 四要素关系
- **备注**：OBE是当前教育改革的主流方向，要让学生理解其核心思想。

  - 课程设计：知识图谱+学习路径
  - 达成评价：10项子功能+三维加权
  - 持续改进：基于数据的教学调整
  - 技术支撑：数据库+AI+可视化
- **配图建议**：OBE在CKGDT中的实现架构图
- **备注**：说明CKGDT是OBE理念的技术实现平台。

### 幻灯片5：达成度评价系统

- **标题**：10项子功能构成的评价体系
- **要点**：
  - 10项子功能：
    1. 平时成绩管理
    2. 实验成绩管理
    3. 考核成绩管理
    4. 贡献分管理
    5. 成绩批次管理
    6. 三维加权计算
    7. 达成度报告生成
    8. 试卷分析
    9. 章节达成度分析
    10. 持续改进建议
  - 数据来源：平时/实验/考核/贡献四类成绩
- **配图建议**：10项子功能列表 + 功能关系图
- **备注**：达成度评价是一个完整的体系，不是单一功能。

### 幻灯片6：三维成绩加权模型

- **标题**：科学的成绩计算方法
- **要点**：
  - 平时成绩（30%）：出勤、课堂互动、作业
  - 实验成绩（30%）：实验提交、实验报告、实验创新
  - 考核成绩（40%）：项目考核、答辩表现、作品质量
  - 加权计算：总分 = 平时×30% + 实验×30% + 考核×40%
  - 贡献分：团队项目中的个人贡献系数
  - 成绩分布：支持正态分布调整
- **配图建议**：三维加权计算公式 + 权重饼图
- **备注**：加权模型要根据课程特点调整权重。

### 幻灯片7：平时成绩管理

- **标题**：平时成绩的多维度评估
- **要点**：
  - 出勤：签到记录（checkin_sessions + checkin_records）
  - 课堂互动：课堂消息参与度
  - 作业完成：作业提交及时性和质量
  - 学习态度：登录频率、资源访问
  - 平时成绩 = 各项加权平均
  - 数据来源：多个数据表综合计算
- **配图建议**：平时成绩构成图 + 数据来源说明
- **备注**：平时成绩要多维度评估，避免单一指标。

### 幻灯片8：实验成绩管理

- **标题**：实验成绩的评估方法
- **要点**：
  - 实验提交：提交及时性、完成度
  - 实验报告：报告质量、分析深度
  - 实验创新：创新性、改进思路
  - 实验互评：同伴评价分数
  - AI批阅：AI初步评分
  - 实验成绩 = 各实验加权平均
- **配图建议**：实验成绩构成图 + 评估维度说明
- **备注**：实验成绩要体现"动手能力"和"创新能力"。

### 幻灯片9：考核成绩管理

- **标题**：项目考核的成绩计算
- **要点**：
  - 项目得分：项目完成质量（5维评分）
  - 答辩表现：答辩评分（多位评委）
  - 贡献度：团队成员贡献系数
  - 个人得分 = 团队项目得分 × 贡献度系数
  - 成绩统计：分布分析、排名、等级划分
  - 数据来源：assessment相关表
- **配图建议**：考核成绩计算流程图 + 贡献度系数说明
- **备注**：考核成绩要公平反映个人在团队中的贡献。

### 幻灯片10：贡献分管理

- **标题**：贡献分的计算与应用
- **要点**：
  - 贡献分来源：Git提交分析 + 互评 + 教师评价
  - 计算方法：加权平均（Git 40% + 互评 30% + 教师 30%）
  - 应用：贡献度系数 = 个人贡献分 / 团队平均贡献分
  - 成绩调整：个人最终成绩 = 团队成绩 × 贡献度系数
  - 公平性：防止"搭便车"和"过度贡献"
- **配图建议**：贡献分计算公式 + 贡献度系数示例
- **备注**：贡献分机制是团队项目公平性的保障。

### 幻灯片11：试卷分析功能

- **标题**：智能试卷分析
- **要点**：
  - 成绩分布：直方图展示成绩分布
  - 题目难度：每题的正确率分析
  - 章节达成度：各章节的平均达成度
  - 区分度：题目对不同水平学生的区分能力
  - 分析报告：自动生成试卷分析报告
- **配图建议**：试卷分析报告示例 + 图表展示
- **备注**：试卷分析帮助教师了解教学效果。

### 幻灯片12：持续改进机制

- **标题**：基于数据的教学改进
- **要点**：
  - 数据驱动：基于达成度数据发现问题
  - 改进方向：课程内容、教学方法、评价方式
  - 改进循环：Plan→Do→Check→Act（PDCA）
  - 改进记录：记录每次改进的内容和效果
  - 目标：持续提升课程质量和学生学习效果
- **配图建议**：PDCA持续改进循环图 + 改进记录示例
- **备注**：持续改进是OBE的核心要求。

### 幻灯片13：教学归档概述

- **标题**：什么是教学归档？
- **要点**：
  - 定义：系统化整理和保存教学过程文档
  - 目的：教学质量保障、专业认证、历史追溯
  - 归档范围：教学大纲、教案、试卷、成绩、总结
  - 30+种文档类型：覆盖教学全过程
  - 归档方式：自动生成 + 手动整理
- **配图建议**：教学归档范围图 + 文档类型清单
- **备注**：归档不是"事后补材料"，而是"过程化记录"。

### 幻灯片14：4阶段归档流程

- **标题**：教学归档的完整流程
- **要点**：
  - 阶段1：课前归档——教学大纲、教案、课件
  - 阶段2：课中归档——教学记录、学生数据、过程文档
  - 阶段3：课后归档——试卷、成绩、总结
  - 阶段4：认证归档——评估报告、改进记录
  - 每个阶段：自动生成+教师确认+存档
- **配图建议**：4阶段归档流程图 + 各阶段文档清单
- **备注**：归档要贯穿整个教学过程，不能等到最后才做。

### 幻灯片15：30+种归档文档

- **标题**：归档文档全览
- **要点**：
  - 教学文件（8种）：大纲、教案、课件、进度、计划
  - 学生数据（6种）：成绩册、达成度报告、分析报告
  - 考核文件（5种）：试卷、答案、评分标准、成绩分析
  - 实验文件（4种）：实验大纲、提交记录、批阅结果
  - 总结文件（5种）：教学总结、改进报告、认证材料
  - 其他（6种）：通知、签到、问卷、反馈
- **配图建议**：30+种文档分类列表 + 重要程度标注
- **备注**：不同学校要求不同，可根据需要调整归档清单。

### 幻灯片16：AI归档助手

- **标题**：AI驱动的智能归档
- **要点**：
  - 三段式提示词架构：
    - 角色定义：你是一位教学归档专家
    - 任务描述：根据教学数据生成归档文档
    - 输出格式：Markdown格式，包含标题/正文/数据
  - 自动生成：根据模板自动生成文档初稿
  - 智能填充：从数据库提取数据自动填充
  - 教师审核：AI生成→教师确认→最终归档
- **配图建议**：三段式提示词架构图 + 生成示例
- **备注**：AI归档助手大幅减少教师的归档工作量。

### 幻灯片17：一键结课功能

- **标题**：结课一键搞定
- **要点**：
  - 功能：一键生成所有归档文档并打包
  - 输入：课程ID、结课时间
  - 处理：调用AI归档助手生成所有文档
  - 输出：ZIP包（含30+种文档）
  - 附加功能：生成总结报告、导出成绩
  - 技术实现：course_ware_service + AI
- **配图建议**：一键结课流程图 + 输出文件列表
- **备注**：一键结课是归档功能的终极体现。

- **标题**：多格式文档支持
- **要点**：
  - 导入格式：MHTML、XLSX、DOCX、PDF
  - 导出格式：Markdown、DOCX、PDF
  - 批量导入：支持批量导入学生数据
