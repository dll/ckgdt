# 第6章 达成度评价矩阵

## 节点一：目标1-知识图谱建模能力（100分）
### 定义
掌握知识图谱的基本概念、建模方法与可视化技术。
### 达成度计算
目标1达成度 = 平时得分×0.15/满分×0.15 + 实验得分×0.10/满分×0.10 + 期末得分×0.05/满分×0.05
### 评价标准
| 等级 | 标准 |
|------|------|
| 优秀 | 概念抽取准确完整，关系定义合理，图谱可视化清晰美观 |
| 良好 | 概念基本完整，关系定义合理，图谱能正确呈现 |
| 合格 | 概念有遗漏，关系基本正确，图谱基本可读 |
| 不合格 | 概念严重缺失或关系定义错误，图谱无法理解 |
### 支撑环节
- 平时作业：知识图谱建模基础（权重 0.15）
- 实验一：平台部署与图谱浏览（权重 0.10）
- 实验二：知识图谱构建与导入（权重 0.10）
- 期末：知识图谱构建方向（权重 0.05）

## 节点六：达成度综合计算（100分）
### 定义
课程目标达成度的综合计算方法。
### 计算公式
课程总达成度 = Σ（各目标达成度 × 目标权重）
= 目标1达成度×0.15 + 目标2达成度×0.20 + 目标3达成度×0.25 + 目标4达成度×0.20 + 目标5达成度×0.20
### 达成度阈值
| 达成度 | 评价 |
|--------|------|
| ≥0.70 | 达标 |
| 0.60-0.69 | 基本达标 |
| <0.60 | 未达标 |
