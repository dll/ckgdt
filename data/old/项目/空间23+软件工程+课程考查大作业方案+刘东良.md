## 一、考核目标

本课程考查大作业旨在全面检验学生对"软件工程理论+空间信息特色+AI技术融合"三位一体知识体系的掌握程度，具体考核以下课程目标：

| 课程目标 | 考核内容 |
|----------|----------|
| **目标1** | 空间软件工程领域的职业素养与社会责任感，地理信息保密、数据安全等行业规范的运用 |
| **目标2** | 空间信息系统的软件工程化方法（需求分析/数据建模/GIS架构设计/编码实现/软件测试），AI辅助工具的运用能力 |
| **目标3** | 终身学习意识与创新精神，空间AI软件工程前沿技术的了解与初步应用能力 |
| **目标4** | 空间信息系统安全设计、安全测试与评估能力 |

## 二、大作业概述

### 2.1 项目名称

**滁州亭城GIS系统（TingChengGIS）——多模态空间信息系统开发**

### 2.2 项目背景

滁州素有"亭城"美誉，本大作业以滁州亭城文化为背景，要求学生分组完成一个完整的多模态空间信息系统的工程化开发。项目覆盖从需求分析、系统设计、编码实现、软件测试到安全评估的完整软件生命周期，全面检验学生对空间软件工程核心技能的掌握程度。

### 2.3 考核形式

**项目设计 + 答辩**

- 各小组分组完成TingChengGIS子系统的工程化设计与编码实现
- 提交完整的技术文档和代码
- 现场答辩（PPT汇报 + 系统演示）

### 2.4 成绩构成

最终成绩由过程性考核成绩（40%）和期末考核成绩（60%）组成，重点考核专业技能与AI应用能力的综合运用。

**过程性考核（40%）：**

- 平时成绩（20%）：作业（10%）、课堂表现（5%）、AI工具实操表现（5%）
- 实验成绩（20%）：实验报告（10%）、实验作品（5%）、小组协作（5%）

**期末考核（60%）：** 采用项目设计+答辩形式，要求学生分组完成小型空间信息系统（如"滁州亭城GIS系统"）的工程化设计与编码实现，提交需求规格说明书、设计说明书、核心代码、测试报告、安全分析报告，进行现场答辩。

| 考核环节 | 权重 | 说明 |
|----------|------|------|
| 技术文档 | 24% | 需求规格说明书、设计说明书、核心代码、测试报告、安全分析报告 |
| 系统实现 | 18% | 系统功能完整度、代码质量、运行效果 |
| 答辩表现 | 12% | PPT汇报、系统演示、问答环节 |
| 团队协作 | 6% | 组内分工合理、Gitee仓库提交记录、小组互评 |

## 八、注意事项

### 8.1 学术诚信

1. 严禁抄袭他人代码或文档，一经发现按学校相关规定处理
2. AI工具辅助生成的代码需标注来源，并经过人工审查和修改
3. 数据采集必须真实，不得伪造空间数据
4. 每个学生需独立采集数据，填充collector_id确保数据可追溯

### 8.2 提交要求

1. 所有文档提交至泛雅平台对应作业入口
2. 所有代码提交至各组Gitee仓库
3. 迟交扣分：迟1天扣10%，迟2天扣20%，超3天不予接收
4. 文档格式统一为PDF（Markdown源文件同时提交）
5. EA UML模型需提交.eap/.eapx项目文件及导出图片

### 8.3 分组管理

1. 每组设组长1名，负责项目管理和协调
2. 组员分工在Gitee仓库README.md中明确标注
3. 组内成员互评结果影响个人最终成绩
4. 如需调整分组，须在第2周前向教师申请

### 8.4 AI工具使用规范

1. 本课程鼓励使用AI工具辅助开发，但必须注明使用方式
2. 在文档中需附"AI辅助开发记录"，包括：
   - 使用的AI工具名称及版本
   - 具体使用场景（需求分析/代码生成/测试用例生成/代码审查等）
   - AI生成内容的人工审查与修改记录
3. 禁止完全依赖AI生成的内容不经审查直接提交
