### 1. 🌳 图谱技能（graph）

| 字段 | 内容 |
|------|------|
| **ID** | `graph` |
| **名称** | 图谱技能 |
| **图标** | `account_tree` (蓝色) |
| **描述** | 利用AI根据指定主题自动生成知识图谱的核心概念和关系结构。系统会分析主题领域，提取关键概念节点，建立概念间的层次和关联关系，输出结构化的知识图谱方案，可直接用于教学设计和课程规划。 |

- 教师备课：为新章节生成知识图谱大纲
- 课程规划：梳理技术体系的概念层次关系

**输入要求**：用户输入一个知识点或章节主题（如"Flutter Widget 生命周期"）

**使用场景**：

**示例对话**：
```
用户：Flutter Widget 生命周期
助手：
## Flutter Widget 生命周期

### 概述
Widget 生命周期是 Widget 从创建到销毁的完整过程，理解它对管理状态和资源至关重要。

### 核心概念

#### StatelessWidget
```dart
class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Text('Hello');
  }
}
```
- 无状态，build() 被调用一次即返回

#### StatefulWidget
```dart
class MyStatefulWidget extends StatefulWidget {
  @override
  _MyStatefulWidgetState createState() => _MyStatefulWidgetState();
}

class _MyStatefulWidgetState extends State<MyStatefulWidget> {
  @override
  void initState() {
    super.initState();  // 初始化，只调用一次
  }

  @override
  void dispose() {
    super.dispose();  // 销毁，清理资源
  }

  @override
  Widget build(BuildContext context) {
    return Text('Hello');
  }
}
```

### 关键对比
| 生命周期 | StatelessWidget | StatefulWidget |
|----------|-----------------|---------------|
| initState | ❌ | ✅ 一次 |
| build | ✅ 一次 | ✅ 多次 |
| dispose | ❌ | ✅ 一次 |

### ⚠️ 易错点
1. 在 initState 中使用 Scaffold.of(context) → 应改用 WidgetsBinding.instance.addPostFrameCallback
2. 忘记调用 super.dispose() → 可能导致内存泄漏
3. 在 build 中执行耗时操作 → 应移到 initState 或异步方法中
```

class DatabaseHelper {

### 9. 🏅 达成技能（achievement）

| 字段 | 内容 |
|------|------|
| **ID** | `achievement` |
| **名称** | 达成技能 |
| **图标** | `emoji_events` (深橙色) |
| **描述** | 面向当前课程生成OBE达成度分析、材料审核和归档闭环建议。联动大纲、进度表、课程表、成绩、达成报告和结课材料，辅助教师完成生成、审核、编辑、预览、打印、归档。 |

**输入要求**：用户输入达成度相关指令（如"达成材料一键审核"、"课程达成度分析"）

**输出格式**：Markdown 格式，包含：
1. 课程目标与考核依据梳理
2. 期初、期中、期末、结课材料状态审核
3. 达成度评价方法和计算依据
4. 缺口与风险清单
5. 一键生成、审核、打印、归档前的操作建议
6. 持续改进措施（CQI）和下一轮教学优化

**内部调用的Agent/工具**：
- 调用 `AchievementAuditContextService.buildAuditMarkdown()` 获取审核上下文
- 调用 `AchievementDao` 查询达成度数据
- 调用 `AiService.chatWithMeta()` 生成分析报告

**使用场景**：
- 期末归档前的材料完整性检查
- OBE达成度量化分析
- 持续改进措施（CQI）规划

**示例对话**：
```
用户：达成材料一键审核
助手：
## 课程达成材料审核报告

### 课程信息
- 课程：课程知识图谱与数字孪生
- 教师：张老师
- 学期：2025-2026学年第二学期

### 材料状态
| 材料 | 状态 | 备注 |
|------|------|------|

| 教学进度表 | ✅ 已生成 | 执行率 85% |

### 缺口与风险

```

### 10. 📁 归档技能（archive）

| 字段 | 内容 |
|------|------|
| **ID** | `archive` |
| **名称** | 归档技能 |
| **图标** | `archive` (棕色) |
| **描述** | 根据课程类型（考试/考查）和教学阶段（期初/期中/期末），AI自动生成规范的教学归档文档。覆盖课程总结、试卷审核表、教学过程记录等常见归档类型，支持一键生成和打印，大幅减少教师归档工作量。 |

**输入要求**：用户输入归档类型和教学阶段（如"期末课程总结"、"试卷命题审核表"）

**输出格式**：Markdown 格式，包含：
1. 文档标题和基本信息（课程、学期、教师）
2. 正文结构（根据文档类型自动适配）
3. 表格和清单（如有需要）
4. 签名和日期栏
5. 归档说明

**内部调用的Agent/工具**：
- 调用 `ArchiveAgent.generateDocument()` 生成归档文档
- 调用 `ArchiveTemplateLoader` 加载历届模板作为参考
- 调用 `ArchiveContextService.collectForPrompt()` 收集系统事实数据
- 调用 `AiService.chatWithMeta()` 生成文档内容

**使用场景**：
- 期末归档：生成课程总结、试卷审核表、成绩分析等
- 期中检查：生成进度执行检查、作业批阅统计
- 期初准备：生成教学大纲、教学进度表、教学教案

## 附录：技能与智能体的对应关系

| 技能ID | 调用的Agent | 关系说明 |
|--------|------------|---------|
| `graph` | graph agent + SpecialAgentTools | 技能直接调用AI生成，Agent可落库 |
| `path` | tutor agent | 技能为轻量入口，Agent提供完整辅导 |
| `learning` | tutor agent | 技能为轻量入口，Agent提供完整辅导 |
| `quiz` | quiz agent + SpecialAgentTools | 技能直接调用AI生成，Agent可落库 |
| `repo` | repo agent | 技能调用AI分析，Agent提供工具查询 |
| `assessment` | assessment agent | 技能为轻量入口，Agent提供完整功能 |
| `lab` | lab agent + SpecialAgentTools | 技能直接调用AI生成，Agent可落库 |
| `works` | works agent | 技能为轻量入口，Agent提供完整功能 |
| `achievement` | achievement agent + AuditContextService | 技能依赖系统上下文，Agent提供完整功能 |
| `archive` | archive agent + ArchiveContextService | 技能依赖系统上下文，Agent提供完整功能 |

**设计原则**：
- **技能** = 轻量级AI入口，一键生成内容，结果保存到 `skill_results` 表
- **智能体** = 完整的对话式交互，支持多轮对话、工具调用、会话上下文
- 技能适合"一次生成"场景，智能体适合"深度交互"场景
