## 幻灯片内容大纲

### 幻灯片1：封面

- **标题**：学生端学习体验与自主学习
- **要点**：
  - 课程名称：CKGDT平台
  - 本章学习目标：理解学生端功能设计与自主学习支持
  - 教师信息
- **配图建议**：学生端界面截图 + 学习场景插图
- **备注**：说明学生端是平台的"用户界面"，设计质量直接影响学习效果。

### 幻灯片2：本章目录

- **标题**：本章内容概览
- **要点**：
  - 学生端导航与学习流程
  - 学习中心功能详解
  - 知识图谱学习体验
  - 测验与错题管理
  - 学习路径与规划
  - 学习分析与可视化
  - 作品展示与协作互动
- **配图建议**：章节导航流程图
- **备注**：本章内容丰富，建议分两次课完成。

### 幻灯片3：学生端导航结构

- **标题**：学生端界面布局
- **要点**：
  - 底部导航6项：首页、图谱、学习、实验、考核、作品
  - AppBar入口：搜索、通知、用户菜单
  - 角色差异化：学生端与教师端导航对比
  - 导航设计原则：扁平化、直观、减少层级
  - 页面切换：Navigator.push子页面路由
- **配图建议**：学生端导航结构图 + 界面截图
- **备注**：让学生先熟悉整体界面布局，再逐个功能深入。

### 幻灯片4：5步学习流程

- **标题**：学生学习的完整旅程
- **要点**：
  - 第1步：浏览知识图谱，了解课程结构
  - 第2步：进入学习中心，观看视频/阅读文档
  - 第3步：完成章节测验，检验学习效果
  - 第4步：查看学习分析，了解掌握情况
  - 第5步：参与实验实践，完成作品展示
  - 流程特点：循环迭代，可根据需要反复学习
- **配图建议**：5步学习流程环形图
- **备注**：强调学习是循环过程，不是线性完成。

### 幻灯片5：学习中心——视频学习

- **标题**：视频学习功能
- **要点**：
  - 视频列表：按章节分类，支持搜索
  - 播放功能：进度记忆、倍速播放、全屏
  - 学习记录：自动记录观看时长和进度
  - AI助手：视频内容问答、知识点提取
  - 技术实现：VideoListPage + video_service
- **配图建议**：视频播放界面截图 + 功能标注
- **备注**：视频是学习中心的核心内容，功能设计要简洁易用。

### 幻灯片6：学习中心——文档学习

- **标题**：文档学习功能
- **要点**：
  - 文档类型：PDF、PPT、Word
  - 在线预览：内嵌PDF阅读器
  - 资源索引：按章节分类，支持筛选
  - 下载管理：离线缓存、下载进度
  - AI辅助：文档摘要、关键概念提取
- **配图建议**：文档预览界面截图 + 功能标注
- **备注**：说明文档学习与视频学习的互补关系。

### 幻灯片7：学习中心——AI助手

- **标题**：智能学习助手
- **要点**：
  - 对话入口：每个学习页面都有AI助手按钮
  - 知识问答：基于RAG检索增强的回答
  - 上下文感知：根据当前学习内容提供帮助
  - 多轮对话：支持追问和深入讨论
  - 历史记录：保存对话历史，可随时回顾
- **配图建议**：AI助手对话界面截图 + 对话示例
- **备注**：AI助手是学习中心的"智能导师"，要让学生养成使用习惯。

### 幻灯片8：知识图谱学习——5种视图

- **标题**：用图谱探索知识世界
- **要点**：
  - 树状视图：清晰展示知识层次
  - 力导向视图：发现知识关联
  - 环形视图：聚焦核心概念
  - 矩阵视图：分析关系密度
  - 自定义视图：个性化布局
  - 视图切换：一键切换，适应不同学习需求
- **配图建议**：5种视图的缩略图并排展示
- **备注**：每种视图适合不同的学习场景，学生可以自由选择。

### 幻灯片9：知识图谱学习——交互功能

- **标题**：图谱交互体验
- **要点**：
  - 节点点击：查看知识点详情、关联资源
  - 缩放拖拽：自由探索图谱
  - 收藏管理：收藏重要节点，快速访问
  - 搜索定位：输入关键词快速找到节点
  - 路径高亮：显示从起点到终点的学习路径
- **配图建议**：图谱交互操作演示图
- **备注**：交互设计要直观，减少学习成本。

### 幻灯片10：章节测验——题目设计

- **标题**：测验题目体系
- **要点**：
  - 题型：四选一选择题（单一最佳答案）
  - 题目来源：教师出题 + AI生成
  - 难度分级：简单/中等/困难
  - 知识点关联：每题关联图谱节点
  - 题库管理：52道预置题目 + 自定义扩展
- **配图建议**：测验题目界面截图 + 题目结构说明
- **备注**：测验是检验学习效果的重要手段。

### 幻灯片11：章节测验——答题与反馈

- **标题**：答题体验设计
- **要点**：
  - 答题流程：选题→选择→提交→查看结果
  - 即时反馈：正确/错误提示 + 解析
  - AI解析：AI生成详细解题过程
  - 知识路径建议：根据错题推荐复习路径
  - 进度跟踪：记录每次测验的成绩
- **配图建议**：答题流程图 + 反馈界面截图
- **备注**：即时反馈能强化学习效果，要让学生养成"做题→看解析"的习惯。

### 幻灯片12：错题本管理

- **标题**：智能错题管理
- **要点**：
  - 自动记录：答错的题目自动加入错题本
  - 错误统计：times（累加错误次数）、last_wrong_time
  - 错题分类：按章节/知识点分类
  - 复习推荐：根据错误频率推荐复习优先级
  - 重做功能：错题重做，检验是否掌握
- **配图建议**：错题本界面截图 + 错误统计图表
- **备注**：错题本是"个性化学习"的基础，要定期回顾。

### 幻灯片13：学习路径规划

- **标题**：AI驱动的学习路径
- **要点**：
  - 路径生成：基于图谱前置关系自动生成
  - 个性化调整：根据学习进度动态优化
  - 学习计划：设定目标、分解任务、安排时间
  - 学习链路：可视化展示学习进度
  - 路径推荐：RAG检索增强的资源匹配
- **配图建议**：学习路径可视化 + 路径生成流程图
- **备注**：学习路径是"因材施教"的技术实现。

### 幻灯片14：学习分析——进度可视化

- **标题**：用数据看学习
- **要点**：
  - 学习时间：每日/每周学习时长统计
  - 知识掌握度：各节点的达成度百分比
  - 进度条：整体学习进度可视化
  - 对比分析：与班级平均对比
  - 时间趋势：学习时间的变化曲线
- **配图建议**：进度可视化仪表盘截图
- **备注**：数据可视化能让学生直观看到自己的学习状态。

### 幻灯片15：学习分析——薄弱诊断

- **标题**：精准识别学习薄弱点
- **要点**：
  - 诊断方法：基于测验成绩+学习记录综合分析
  - 薄弱知识点：错误率高、学习时间短的节点
  - 知识路径分析：前置知识未掌握导致的连锁问题
  - 诊断报告：自动生成薄弱点诊断报告
  - 改进建议：针对性的复习资源推荐
- **配图建议**：薄弱诊断报告示例 + 知识路径分析图
- **备注**：薄弱诊断是"精准教学"的基础。

### 幻灯片16：学习分析——成长曲线与热力图

- **标题**：可视化成长轨迹
- **要点**：
  - 成长曲线：学习时间与成绩的长期趋势
  - 活跃热力图：30天学习活跃度日历视图
  - 5维雷达图：知识掌握/实验/考核/作品/协作
  - 数字孪生仪表盘：学生画像的可视化呈现
  - 个性化报告：基于数据的自我认知
- **配图建议**：成长曲线图 + 活跃热力图 + 雷达图并排展示
- **备注**：这些可视化工具帮助学生建立"数据驱动的自我认知"。

### 幻灯片17：作品展示与协作互动

- **标题**：展示与协作
- **要点**：
  - 作品展示：上传作品、5维评分、排行榜
  - 匿名机制：评审过程匿名，保证公平
  - 协作互动：课堂消息、协作开发
  - 点赞评论：同学互评、点赞鼓励
  - 成就系统：作品获奖、贡献分
- **配图建议**：作品展示界面 + 协作互动示例
- **备注**：作品展示是"学以致用"的体现，协作互动促进同伴学习。

### 幻灯片18：个人中心与AI技能

- **标题**：个人中心与AI工具箱
- **要点**：
  - 个人中心：学习统计、成就徽章、设置
  - AI技能：9个AI技能（辅导/测验/课件/图谱等）
  - 学习计划：制定和管理个人学习计划
  - 聊天历史：保存与AI的对话记录
  - 数据导出：学习数据导出功能
- **配图建议**：个人中心界面 + AI技能列表
- **备注**：个人中心是学生的"学习仪表盘"，要让学生养成定期查看的习惯。

### 幻灯片19：实践任务——完整学习流程体验

- **标题**：课堂实践：体验完整学习流程
- **要点**：
  - 任务：以学生身份完成一章的完整学习
  - 步骤1：浏览图谱了解章节结构（5分钟）
  - 步骤2：进入学习中心观看视频/阅读文档（10分钟）
  - 步骤3：完成章节测验（5分钟）
  - 步骤4：查看学习分析报告（5分钟）
  - 时间：25分钟
- **配图建议**：实践任务清单 + 操作步骤提示
- **备注**：让学生从学生视角体验平台，理解设计意图。

- **标题**：本章知识回顾

  - 知识图谱：5种视图 + 交互探索
