# 多智能体系统图谱

## 核心概念

### 智能体层级
- **基础层**：`BaseAgent` 基类、会话管理、AI 调用
- **注册层**：`AgentRegistry` 智能体注册、匹配、调度
- **应用层**：18 个专业智能体

### 智能体分类
- **教学辅助**：`TutorAgent`、`QuizAgent`、`LabAgent`
- **批阅评审**：`GradingAgent`、`LabGradingAgent`、`AssessmentGradingAgent`
- **内容生成**：`GraphAgent`、`CoursewareAgent`、`CourseGenAgent`
- **系统管理**：`VoiceAgent`、`SafetyAgent`、`ArchiveAgent`
- **数字孪生**：`VirtualStudentAgent`、`VirtualTeacherAgent`

### 工具系统
- **导航工具**：`navigate_tab`、`navigate_sub_page`、`go_back`
- **数据工具**：`search_nodes`、`get_node_details`、`query_achievement`
- **生成工具**：`generate_graph`、`generate_quiz`、`generate_video`

## 概念关系

| 源概念 | 关系 | 目标概念 | 说明 |
|--------|------|----------|------|
| 基础层 | 被继承 | 应用层 | 所有 Agent 继承 BaseAgent |
| 注册层 | 管理 | 应用层 | 注册、匹配、调度 |
| 应用层 | 调用 | 工具系统 | Agent 使用工具执行任务 |
| 教学辅助 | 服务 | 学生 | 辅导、测验、实验指导 |
| 批阅评审 | 服务 | 教师 | 智能批阅、成绩分析 |
| 内容生成 | 服务 | 课程 | 生成图谱、课件、资源 |
| 数字孪生 | 模拟 | 师生 | 虚拟学生、虚拟教师 |

## 调用流程

```
用户输入 → AgentChatOverlay → AgentRegistry 匹配
    ↓
BaseAgent.handleMessage() → AI 推理 → 工具调用
    ↓
工具执行 → 结果返回 → AI 总结 → 用户输出
```

## 平台实现

- **智能体定义**：`lib/services/agent/agents/` (18 个)
- **工具执行**：`SpecialTools` 统一路由
- **对话入口**：`AgentChatOverlay` 全局浮层
- **Prompt 模板**：`assets/agent_prompts/` (28 个)
