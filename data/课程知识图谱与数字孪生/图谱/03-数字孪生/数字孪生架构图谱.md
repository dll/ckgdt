# 数字孪生架构图谱

## 核心概念

### 数字孪生层级
- **物理层**：真实教学环境（教室、学生、教师）
- **数据层**：学习行为数据、成绩数据、交互数据
- **模型层**：学生模型、教师模型、课程模型
- **应用层**：虚拟学生、虚拟教师、智能督导

### 学生数字孪生
- **学习画像**：知识掌握度、学习风格、进度轨迹
- **行为模拟**：答题模式、学习路径选择、互动偏好
- **预测分析**：成绩预测、风险预警、个性化推荐

### 教师数字孪生
- **教学画像**：教学风格、内容偏好、评价模式
- **督导辅助**：课堂观察、教学建议、资源推荐
- **决策支持**：学情分析、教学优化、课程改进

## 概念关系

| 源概念 | 关系 | 目标概念 | 说明 |
|--------|------|----------|------|
| 物理层 | 映射 | 数据层 | 真实行为 → 数据记录 |
| 数据层 | 喂养 | 模型层 | 数据训练模型 |
| 模型层 | 驱动 | 应用层 | 模型生成虚拟实体 |
| 学生数字孪生 | 依赖 | 学习画像 | 画像驱动行为模拟 |
| 教师数字孪生 | 依赖 | 教学画像 | 画像驱动督导辅助 |
| 应用层 | 反馈 | 物理层 | 虚拟建议 → 真实改进 |

## 数据流

```
物理层 → 数据采集 → 数据层 → 模型训练 → 模型层
    ↑                                      ↓
    ← 虚拟建议 ← 应用层 ← 行为模拟 ←
```

## 平台实现

- **数据采集**：学习记录、测验成绩、实验提交、作品展示
- **模型训练**：AI 智能体分析学生行为模式
- **虚拟生成**：`VirtualStudentAgent` / `VirtualTeacherAgent`
- **应用展示**：`VirtualTwinPage` 数字孪生仪表盘
