# 学习分析模型图谱

## 核心概念

### 分析维度
- **知识维度**：概念掌握度、知识关联度、学习路径
- **行为维度**：学习时长、互动频率、资源使用
- **成绩维度**：测验成绩、实验成绩、作品评分
- **时间维度**：学习节奏、进度轨迹、周期规律

### 分析方法
- **描述性分析**：发生了什么（统计、可视化）
- **诊断性分析**：为什么发生（归因、关联）
- **预测性分析**：将要发生什么（预测、预警）
- **规范性分析**：应该怎么做（推荐、优化）

### 分析产出
- **达成度报告**：课程目标达成情况
- **学情分析**：班级/个人学习状态
- **教学建议**：教学改进方向
- **个性化推荐**：学习路径、资源推荐

## 概念关系

| 源概念 | 关系 | 目标概念 | 说明 |
|--------|------|----------|------|
| 知识维度 | 输入 | 描述性分析 | 知识掌握统计 |
| 行为维度 | 输入 | 诊断性分析 | 行为归因分析 |
| 成绩维度 | 输入 | 预测性分析 | 成绩趋势预测 |
| 时间维度 | 输入 | 规范性分析 | 时间优化建议 |
| 描述性分析 | 产出 | 达成度报告 | 统计 → 报告 |
| 诊断性分析 | 产出 | 学情分析 | 归因 → 诊断 |
| 预测性分析 | 产出 | 教学建议 | 预测 → 建议 |
| 规范性分析 | 产出 | 个性化推荐 | 优化 → 推荐 |

## 分析流程

```
数据采集 → 数据清洗 → 维度分析 → 方法选择 → 产出生成
    ↑                                        ↓
    ← 反馈优化 ← 应用实施 ← 报告解读 ←
```

## 平台实现

- **数据采集**：`learning_records`、`quiz_results`、`achievement_scores`
- **分析引擎**：`AchievementService`、`LearningPathService`
- **可视化**：`AchievementPage`、`AnalyticsPage`
- **推荐系统**：`LearningPathAgent`、`RagService`
