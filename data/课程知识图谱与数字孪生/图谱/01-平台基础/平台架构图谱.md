# 平台架构图谱

## 核心概念

### 系统架构
- **表现层**：Flutter 跨平台 UI（Android/Windows/Web/HarmonyOS）
- **业务层**：多智能体框架 + RAG 检索增强
- **数据层**：SQLite 本地数据库（59 张表）+ Gitee 仓库同步
- **服务层**：AI 服务（DeepSeek/智谱）+ 讯飞语音

### 用户角色
- **学生**：图谱浏览、测验练习、实验提交、作品展示
- **教师**：教学管理、智能批阅、成绩分析、通知发布
- **管理员**：系统配置、用户管理、数据导入

## 概念关系

| 源概念 | 关系 | 目标概念 | 说明 |
|--------|------|----------|------|
| 表现层 | 依赖 | 业务层 | UI 调用业务逻辑 |
| 业务层 | 组合 | 多智能体 | 18 个专业 Agent |
| 业务层 | 组合 | RAG 服务 | 课程知识库检索 |
| 数据层 | 存储 | 用户数据 | SQLite 本地持久化 |
| 数据层 | 同步 | Gitee 仓库 | 师生数据双向同步 |
| AI 服务 | 驱动 | 智能体 | DeepSeek/智谱 GLM-4 |
