# 实验四：学习分析仪表盘解读

## 实验类型
综合型实验 | 课程目标3：智能学习路径与学习分析

## 实验目的
1. 掌握学习分析仪表盘的各项指标含义
2. 学会使用薄弱诊断功能定位学习问题
3. 能够基于图谱前置关系设计补救学习路径

## 实验环境
- CKGDT 平台（学生端）
- 浏览器 / 桌面客户端

## 实验步骤

### 步骤1：查看个人学习统计数据
1. 登录平台，点击"学习" Tab
2. 进入"学习进度"页面
3. 查看以下统计数据：
   - **总学习时长**：累计投入时间
   - **已完成节点**：已掌握的知识点数量
   - **测验正确率**：各章节正确率分布
   - **学习天数**：连续学习记录
4. 截图记录各项数据

### 步骤2：使用薄弱诊断功能
1. 在学习中心找到"薄弱诊断"入口
2. 点击进入诊断页面
3. 系统自动分析以下维度：
   - **知识盲区**：未学习或未覆盖的知识点
   - **薄弱环节**：测验正确率低于60%的知识点
   - **遗忘风险**：长时间未复习的知识点
4. 记录诊断结果，列出Top 5薄弱点

### 步骤3：查看成长曲线
1. 进入"成长曲线"页面
2. 观察折线图的趋势变化：
   - 横轴：时间（天/周）
   - 纵轴：综合评分 / 知识覆盖率
3. 分析曲线中的关键拐点：
   - 上升期：哪些学习行为带来了提升
   - 平台期：停滞原因分析
   - 下降期：影响因素识别
4. 导出或截图成长曲线

### 步骤4：设计补救学习路径
1. 选择一个假设场景："学习困难学生"（某章节测验正确率<50%）
2. 打开知识图谱，查看该章节的前置依赖关系
3. 按以下步骤设计补救路径：

```
补救路径设计框架：

1. 问题定位
   - 薄弱知识点：XXX
   - 前置缺失：XXX（前置知识点未掌握）

2. 路径规划
   第1步：复习前置概念A（预计30分钟）
   第2步：学习核心概念B（预计45分钟）
   第3步：完成练习题巩固（预计20分钟）
   第4步：进入目标章节学习

3. 资源配置
   - 视频教程：XXX
   - 图谱节点：XXX
   - 练习题库：XXX

4. 效果验证
   - 阶段测验：完成XX题
   - 目标正确率：≥70%
```

4. 将路径方案整理为文档

## 实验要求
- 提交学习分析报告（含数据截图）
- 提交补救路径设计方案（Markdown格式）
- 报告需包含：数据分析、问题诊断、路径规划三部分

## 思考题
1. 薄弱诊断功能对自主学习有哪些帮助？
2. 知识图谱的前置关系在补救路径设计中起什么作用？
3. 如何量化评估补救学习路径的有效性？
