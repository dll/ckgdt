# 第3章 学生端学习体验与自主学习

| 项目 | 内容 |
|------|------|
| **课程名称** | 课程知识图谱与数字孪生平台（CKGDT） |
| **章节** | 第3章 学生端学习体验与自主学习 |
| **课时** | 4学时（理论2学时 + 实验2学时） |
| **课程目标** | 目标1-3：掌握学生端功能设计、理解自主学习路径、体验智能学习支持 |

---

## 一、教学目标

1. 熟悉CKGDT学生端的7项底部导航和5步学习流程，理解以学生为中心的UI设计。
2. 掌握学习中心的多媒体资源（视频/PPT/PDF/AI助手）使用方法。
3. 能够运用知识图谱5种视图模式进行自主学习导航，管理学习收藏。
4. 理解测验与错题系统的工作机制，能够利用AI解析和知识路径建议进行针对性学习。

---

## 二、教学重点与难点

| 类型 | 内容 |
|------|------|
| **重点** | 学生端5步学习流程的设计逻辑 |
| **重点** | 知识图谱视图模式在学习中的实际应用 |
| **重点** | 测验→错题→AI解析→路径建议的闭环机制 |
| **难点** | AI学习路径推荐的算法原理理解 |
| **难点** | 学习分析仪表盘数据的解读与教学决策 |

---

## 三、教学方法

- **讲授法**：学生端功能架构、学习流程设计
- **演示法**：完整走通学生端学习流程
- **案例法**：以一名学生完成章节学习为例展示全流程
- **实操法**：教师以学生身份登录体验完整学习流程
- **讨论法**：学生端设计对自主学习的促进作用

---

## 四、教学过程

### 第1课时（理论讲授，2学时，90分钟）

#### 1. 导入环节（5-10分钟）

展示一个场景："学生打开CKGDT，从哪里开始学？学完怎么知道自己掌握了？薄弱环节如何补强？"通过问题链引出学生端学习体验的设计逻辑。

#### 2. 新课讲授（50-55分钟）

**（1）学生端导航与学习流程（15分钟）**

7项底部导航：

| 索引 | Tab | 功能 |
|------|-----|------|
| 0 | 首页 | 通知、快捷入口、学习概览 |
| 1 | 图谱 | 知识图谱浏览与探索 |
| 2 | 学习 | 学习中心、视频、文档 |
| 3 | 实验 | 实验任务提交与报告 |
| 4 | 考核 | 项目考核与答辩 |
| 5 | 作品 | 作品展示与互动 |

5步学习流程：
1. **浏览图谱**：了解知识全貌
2. **观看视频**：学习核心内容
3. **阅读文档**：深化理解
4. **完成测验**：检验掌握度
5. **查看错题**：针对性补强

**（2）学习中心功能详解（15分钟）**
- **视频学习**：播放进度追踪、章节标记
- **PPT/PDF**：在线预览、重点标注
- **AI助手**：学习过程中的智能答疑
- **学习记录**：自动记录学习时长和进度

**（3）知识图谱学习导航（10分钟）**
- 5种视图模式的学习应用：
  - 力导向：发现知识关联
  - 层级：按章节系统学习
  - 树形：按前置关系循序渐进
  - 环形：周期性复习规划
  - 缩略：学习进度概览
- 收藏管理：标记重点/难点概念

**（4）测验与错题系统（10分钟）**
- 章节测验：4选1题型，即时反馈
- AI解析：错题的AI详细解答
- 知识路径建议：基于错题分析推荐学习路径
- 错题本：累加错误次数，智能复习提醒

#### 3. 课堂练习（10分钟）

请学生列出自己认为最重要的3个学生端功能，并说明理由。

#### 4. 小结与作业布置（5分钟）

**小结**：CKGDT学生端以"图谱导航→资源学习→测验检验→错题补强"为核心闭环，支持自主学习。

**作业**：
- 以学生身份完成一个章节的完整学习流程
- 记录学习过程中遇到的3个设计亮点和2个改进建议

---

### 第2课时（实验操作，2学时，90分钟）

#### 1. 导入环节（5分钟）

介绍本节课实验目标：以学生身份完整体验CKGDT学习流程，重点体验AI学习路径和学习分析功能。

#### 2. 新课讲授（25-30分钟）

**（1）学习路径与学习计划（10分钟）**
- AI生成学习路径：基于图谱的前置关系自动规划
- 学习计划：时间维度的学习安排
- 学习链路：已学→在学→待学的路径可视化

**（2）学习分析仪表盘（10分钟）**
- 5维雷达图：知识掌握、学习时长、测验成绩、实验完成、作品贡献
- 活跃热力图：30天学习行为可视化
- 成长曲线：学习进度的时序变化
- 数字孪生仪表盘：学生数字画像概览

**（3）作品展示与协作（10分钟）**
- 作品展示：5维评分、排行榜、匿名机制
- 个人中心：学习档案、收藏、历史记录
- AI技能工具：9种AI辅助学习技能

#### 3. 平台演示（10分钟）

完整演示学生端学习流程：
- 登录学生账号 → 进入图谱 → 选择节点 → 观看视频 → 完成测验
- 查看错题 → 使用AI解析 → 查看知识路径建议
- 进入学习中心 → 查看雷达图和活跃热力图

#### 4. 课堂练习（40-45分钟）

1. 以学生身份登录，完成第1章的测验（15分钟）
2. 查看测验结果和错题解析（10分钟）
3. 查看学习分析仪表盘，解读雷达图数据（10分钟）
4. 使用AI学习路径推荐功能（5分钟）

教师巡回指导，解答操作问题。

#### 5. 小结与作业布置（5分钟）

**小结**：本章完整体验了学生端的学习闭环，理解了数据驱动的个性化学习支持机制。

**作业**：
- 完成至少2个章节的完整学习流程
- 截图并分析自己的学习雷达图数据
- 思考：学生端设计如何为第4章"数字孪生"提供数据基础？
- 预习第4章：数字孪生教学场景设计

---

## 五、课程思政融入点

1. **自主学习能力**：平台设计强调"以学生为中心"，培养学生主动学习、终身学习的意识。
2. **数据伦理**：学习行为数据的采集与使用应遵循知情同意原则，保护学生隐私。
3. **教育技术自信**：CKGDT平台整合了AI、知识图谱等前沿技术，展示中国教育信息化成果。
