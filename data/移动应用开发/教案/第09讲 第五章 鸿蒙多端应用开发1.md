**系统架构分层**

| 层级 | 名称 | 主要功能 |
|------|------|---------|
| 第一层 | 内核层 | 内核抽象层、驱动子系统 |

**分布式软总线**
- 定义：跨设备的通信基础设施
- 作用：实现设备间的高速、低时延、可靠连接
- 特点：自动发现、无缝连接、安全传输

**分布式数据管理**
- 应用数据跨设备同步
- 分布式数据库
- 数据一致性保障

**分布式任务调度**
- 跨设备任务流转
- 多端协同计算
- 资源按需分配

**一次开发多端部署**
- 一套代码适配多种设备形态
- 自适应布局与响应式设计
- 多设备预览与调试

### 第二学时：ArkUI框架与实操演示（45分钟）

#### 4. ArkUI框架与ArkTS语法（18分钟）

**ArkUI开发范式**
- 声明式UI开发（ArkTS）
- 类Web范式（JS/TS + CSS）
- 本课程重点：ArkTS声明式开发

**ArkTS基础语法**

```typescript
@Entry
@Component
struct HelloWorld {
  build() {
    Column() {
      Text('Hello HarmonyOS')
        .fontSize(30)
        .fontColor(Color.Blue)
      
      Button('点击我')
        .width(200)
        .height(50)
        .margin({ top: 20 })
        .onClick(() => {
          console.log('按钮被点击了')
        })
    }
    .width('100%')
    .height('100%')
    .justifyContent(FlexAlign.Center)
  }
}
```

**核心概念**
- `@Component`：组件装饰器，标识一个自定义组件
- `@Entry`：入口装饰器，标识页面入口组件
- `build()`：UI描述方法，返回组件树
- 链式调用：通过`.`连接属性设置，简洁直观

#### 5. 状态管理装饰器（12分钟）

**@State —— 组件内部状态**
- 装饰组件内部的状态变量
- 状态变化时触发UI重新渲染
- 仅在当前组件内部可见

```typescript
@Component
struct Counter {
  @State count: number = 0
  
  build() {
    Column() {
      Text(`计数: ${this.count}`)
        .fontSize(24)
      
      Button('增加')
        .onClick(() => {
          this.count++
        })
    }
  }
}
```

**@Prop —— 父传子单向数据**
- 从父组件接收数据
- 单向数据流：父组件数据变化会同步到子组件
- 子组件不能修改@Prop装饰的变量

**@Link —— 父子双向绑定**
- 父子组件共享同一份数据
- 双向数据绑定：任一方修改都会同步到另一方
- 使用`$`符号传递引用

**状态管理对比表**

| 装饰器 | 作用范围 | 数据流向 | 使用场景 |
|--------|---------|---------|---------|
| @State | 组件内部 | 自身状态 | 组件内部状态管理 |
| @Prop | 父→子 | 单向 | 子组件展示父组件数据 |
| @Link | 父↔子 | 双向 | 父子组件共享状态 |

#### 6. 多端自适应布局（10分钟）

**自适应布局策略**
- 断点式布局：根据屏幕尺寸切换布局方式
- 拉伸式布局：组件尺寸随屏幕比例变化
- 隐藏式布局：小屏隐藏次要内容
- 重排式布局：改变组件排列顺序

**常用布局组件**
- `Column` / `Row`：线性布局
- `Stack`：堆叠布局
- `Grid`：网格布局
- `List`：列表布局
- `Flex`：弹性布局

## 五、学前测验

### 测验说明
本测验旨在检测学习者对鸿蒙系统和ArkUI开发的预备知识掌握程度，帮助确定学习起点。

### 测验题目

**第1题**：HarmonyOS（鸿蒙操作系统）是由哪家公司主导开发的？
A. 小米
B. 华为
C. 阿里巴巴
D. 腾讯

**正确答案**：B

**答案解释**：鸿蒙操作系统（HarmonyOS）是由华为公司自主研发的面向万物互联时代的全场景分布式操作系统。其核心理念是"一次开发，多端部署"，支持手机、平板、智慧屏、车机、智能穿戴等多种设备形态。

---

**第2题**：以下哪个不是HarmonyOS的核心特性？
A. 分布式软总线
B. 分布式数据管理
C. 分布式任务调度
D. 单设备独占模式

**正确答案**：D

**答案解释**：HarmonyOS的核心特性包括分布式软总线、分布式数据管理、分布式任务调度等分布式能力，其设计理念是多设备协同、万物互联，而非单设备独占模式。这也是鸿蒙与传统移动操作系统的本质区别。

---

**第3题**：在ArkUI声明式开发中，用于标识自定义组件的装饰器是？
A. @State
B. @Entry
C. @Component
D. @Prop

**正确答案**：C

**答案解释**：@Component是组件装饰器，用于标识一个结构体是自定义组件。@State用于状态管理，@Entry用于标识页面入口组件，@Prop用于父子组件间单向数据传递。理解这些装饰器的作用是学习ArkTS开发的基础。

---

**第4题**：在鸿蒙ArkTS状态管理中，@State装饰器的作用是？
A. 定义父子组件间双向绑定的数据
B. 定义组件内部的状态变量，状态变化时触发UI更新
C. 从父组件接收数据的单向传递
D. 定义全局共享状态

**正确答案**：B

**答案解释**：@State装饰器用于装饰组件内部的状态变量，当被@State装饰的变量值发生变化时，会触发组件的build()方法重新执行，从而更新UI。这是声明式UI开发中最基础的状态管理方式。

---

**第5题**：HarmonyOS提出的"一次开发，多端部署"理念，最准确的含义是？
A. 一套代码只能在手机和平板上运行
B. 一套代码可以适配多种设备形态，实现多端运行
C. 开发一次后自动部署到所有应用商店
D. 开发一次后可以无限次复制使用

**正确答案**：B

**答案解释**："一次开发，多端部署"是鸿蒙系统的核心优势之一，指的是开发者编写一套代码，可以适配手机、平板、智慧屏、车机、智能手表等多种设备形态，大大降低了多端应用的开发和维护成本。
