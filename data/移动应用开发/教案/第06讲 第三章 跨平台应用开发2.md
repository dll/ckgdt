#### 导入环节设计
**提问**："我们每天使用的App（如微信、淘宝），数据从哪里来？手机App是如何与服务器进行通信的？"
引导学生从用户视角转向技术视角，引出网络通信与API交互的重要性。

#### 案例：Flutter使用Dio发起网络请求
```dart
import 'package:dio/dio.dart';

class ApiService {
  final Dio _dio = Dio();

  ApiService() {
    _dio.options.baseUrl = 'https://api.example.com';
    _dio.options.connectTimeout = Duration(seconds: 5);
    _dio.options.receiveTimeout = Duration(seconds: 3);
    
    // 请求拦截器
    _dio.interceptors.add(InterceptorsWrapper(
      onRequest: (options, handler) {
        // 添加Token
        options.headers['Authorization'] = 'Bearer xxx';
        return handler.next(options);
      },
      onResponse: (response, handler) {
        return handler.next(response);
      },
      onError: (error, handler) {
        return handler.next(error);
      },
    ));
  }

  Future<Map<String, dynamic>> getUserList() async {
    try {
      Response response = await _dio.get('/users');
      return response.data;
    } catch (e) {
      throw Exception('请求失败: $e');
    }
  }
}
```

### 一、单选题（共6题）

**1. 在RESTful API设计中，用于创建资源的HTTP方法是？**
- A. GET
- B. POST
- C. PUT
- D. DELETE

**答案：B**
**解析**：RESTful API中，POST方法用于创建新资源。GET用于获取资源，PUT用于更新资源（整体替换），DELETE用于删除资源。这是REST架构的核心约定之一。

---

**2. JWT（JSON Web Token）的三部分组成不包括以下哪一项？**
- A. Header（头部）
- B. Payload（载荷）
- C. Signature（签名）
- D. Session（会话）

**答案：D**
**解析**：JWT由三部分组成：Header（头部，声明类型和签名算法）、Payload（载荷，存放有效信息如用户ID、过期时间等）、Signature（签名，用于验证消息完整性和真实性）。Session是服务端会话机制，不属于JWT的组成部分。

---

**3. Flutter中最常用的第三方HTTP请求库是？**
- A. Axios
- B. Dio
- C. HttpClient
- D. Fetch

**答案：B**
**解析**：Dio是Flutter生态中最流行的HTTP客户端库，支持拦截器、全局配置、FormData、请求取消、文件下载、超时等丰富功能。Axios主要用于JavaScript/React生态。HttpClient是Dart SDK内置的HTTP客户端，功能相对基础。Fetch是浏览器原生API。

---

**4. 以下哪个传感器可以用于检测设备的旋转和倾斜状态？**
- A. GPS
- B. 加速度计
- C. 陀螺仪
- D. 光线传感器

**答案：C**
**解析**：陀螺仪（Gyroscope）用于测量设备的角速度，可以精确检测设备的旋转和倾斜状态。GPS用于定位，加速度计用于检测加速度和重力方向（可判断横竖屏），光线传感器用于检测环境光强度。

---

**5. Token认证相比Session认证的主要优势是？**
- A. 更安全
- B. 服务端无需存储状态，易于水平扩展
- C. 数据传输更快
- D. 支持更多用户同时在线

**答案：B**
**解析**：Token是无状态的，服务端不需要存储会话信息，只需验证Token签名即可，便于分布式部署和水平扩展。Token通常放在请求头中，支持跨域访问。安全性方面两者各有侧重，传输速度和用户容量不是本质区别。

---

**6. 在HTTP请求中，Token通常放在哪个请求头中？**
- A. Content-Type
- B. Authorization
- C. X-Token
- D. Token

**答案：B**
**解析**：标准做法是将Token放在`Authorization`请求头中，格式为`Bearer <token>`。这是HTTP协议的规范约定，便于各种中间件和框架统一处理。虽然也可以自定义头（如X-Token），但不推荐。

### 二、多选题（共4题）

**7. 以下属于RESTful API设计最佳实践的有？**
- A. 使用名词而非动词作为URI路径
- B. 正确使用HTTP状态码
- C. 版本化管理API
- D. 所有请求都使用POST方法

**答案：ABC**
**解析**：RESTful设计最佳实践包括：使用名词表示资源（如/users而非/getUsers）、正确使用HTTP方法和状态码、API版本化（如/v1/users）、分页和过滤、返回合理的错误信息等。所有请求都用POST违反了REST的设计原则。

---

**8. 以下哪些是移动设备常见的传感器？**
- A. 加速度计（Accelerometer）
- B. 陀螺仪（Gyroscope）
- C. GPS定位
- D. 指纹传感器

**答案：ABCD**
**解析**：现代智能手机集成了多种传感器。加速度计检测设备的加速度运动，陀螺仪检测角速度和旋转，GPS提供地理位置信息，指纹传感器用于生物识别。此外还有光线传感器、距离传感器、磁力计、气压计等。

---

**9. 使用AI编程工具辅助开发时，正确的做法有？**
- A. 直接复制AI生成的所有代码，无需审查
- B. 理解AI生成代码的逻辑后再使用
- C. 对关键代码进行测试验证
- D. 利用AI解释复杂代码，辅助学习

**答案：BCD**
**解析**：使用AI编程工具应保持审慎态度：要理解代码逻辑而非盲目复制、对关键代码进行测试验证、利用AI辅助学习和解释复杂概念。直接复制不审查可能带来安全漏洞、逻辑错误或质量问题。AI是辅助工具，开发者需对最终代码负责。

---

**10. 以下关于HTTP请求拦截器的描述，正确的有？**
- A. 可以在请求发送前统一添加请求头
- B. 可以统一处理错误响应
- C. 可以修改请求参数和URL
- D. 拦截器只能用于添加Token

**答案：ABC**
**解析**：HTTP请求拦截器功能强大，可以在请求发送前进行统一处理（添加请求头、修改参数、URL重写等），也可以在响应返回后统一处理（数据格式化、错误处理、Token刷新等）。添加Token只是拦截器的常见用途之一，并非唯一用途。
