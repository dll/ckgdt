#### 案例：Flutter计数器应用
```dart
import 'package:flutter/material.dart';

void main() => runApp(MyApp());

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: CounterPage(),
    );
  }
}

class CounterPage extends StatefulWidget {
  @override
  _CounterPageState createState() => _CounterPageState();
}

class _CounterPageState extends State<CounterPage> {
  int _counter = 0;

  void _increment() {
    setState(() {
      _counter++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Flutter计数器')),
      body: Center(child: Text('计数: $_counter')),
      floatingActionButton: FloatingActionButton(
        onPressed: _increment,
        child: Icon(Icons.add),
      ),
    );
  }
}
```
通过计数器案例讲解Widget树、StatefulWidget、setState状态更新机制。

#### 案例：React Native计数器组件
```jsx
import React, { useState } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

const CounterApp = () => {
  const [count, setCount] = useState(0);

  return (
    <View style={styles.container}>
      <Text style={styles.text}>计数: {count}</Text>
      <Button title="增加" onPress={() => setCount(count + 1)} />
    </View>
  );
};

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  text: { fontSize: 24, marginBottom: 20 },
});

export default CounterApp;
```

## 五、学前测验

**（第5讲为学前测验，共5道选择题）**

### 单选题

**1. Flutter框架使用的编程语言是？**
- A. JavaScript
- B. Dart
- C. C#
- D. Kotlin

**答案：B**
**解析**：Flutter是Google推出的跨平台UI框架，使用Dart语言开发。Dart是一种面向对象的、类定义的、单继承的语言，兼具JIT（即时编译）和AOT（预先编译）两种编译模式，既能支持开发阶段的热重载，又能在发布时编译为高效的原生机器码。

---

**2. 在Flutter中，一切界面元素的基础是？**
- A. Activity
- B. View
- C. Widget
- D. Component

**答案：C**
**解析**：Flutter采用"一切皆Widget"的设计理念。Widget是Flutter应用的基本构建块，不仅代表UI元素（如按钮、文本），也包括布局、动画、手势处理等。Widget本身是不可变的（immutable），通过Widget树来描述界面结构，通过Element树和RenderObject树来实现实际的渲染。

---

**3. React Native中JSX的作用是？**
- A. 直接操作DOM元素
- B. 在JavaScript中编写类XML结构的UI代码
- C. 编译为原生Java/Kotlin代码
- D. 用于样式表定义

**答案：B**
**解析**：JSX（JavaScript XML）是React的语法扩展，允许开发者在JavaScript代码中编写类似XML/HTML的结构来描述UI。JSX会被Babel等工具编译为普通的JavaScript函数调用（React.createElement），最终通过JavaScript Bridge与原生端通信，渲染为原生组件。

---

**4. Uniapp实现多端编译的核心原理是？**
- A. 运行时动态适配
- B. 编译时将同一份代码转换为各端可运行的代码
- C. 使用WebView统一渲染
- D. 通过虚拟机解释执行

**答案：B**
**解析**：Uniapp的核心是"一次编写，多端发行"。它通过编译时转换，将Vue语法编写的代码分别编译为微信小程序、支付宝小程序、H5、App等不同平台的代码格式。条件编译是其重要特性，通过特殊注释语法（如 `#ifdef MP-WEIXIN`）可以针对不同平台编写差异化代码。

---

**5. 以下关于MAUI框架的描述，错误的是？**
- A. MAUI是Xamarin.Forms的演进版本
- B. MAUI支持Android、iOS、Windows、macOS多平台
- C. MAUI只能使用C#开发，不能使用XAML定义UI
- D. MAUI可以直接调用各平台的原生API

**答案：C**
**解析**：MAUI（Multi-platform App UI）是微软推出的跨平台UI框架，是Xamarin.Forms的继任者。它既可以使用C#代码编写UI，也支持使用XAML（eXtensible Application Markup Language）声明式定义界面。MAUI通过平台特定项目（MAUI.Android、MAUI.iOS等）提供原生API访问能力。
