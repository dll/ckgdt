#### 2. MINA框架介绍（20分钟）

**小程序发展历程**
- 2017年1月正式上线
- 从"用完即走"到"生态闭环"
- 小程序、小游戏、小程序组件三大方向

**MINA框架核心架构**
- 双线程模型：视图层（WebView）+ 逻辑层（JSCore）
- 视图层：WXML + WXSS，负责页面渲染
- 逻辑层：JavaScript，负责业务逻辑
- 通信机制：通过Native层进行数据传输和事件转发
- 优势：数据驱动视图，逻辑与视图分离

**小程序文件结构**
```
├── app.js          // 小程序入口文件
├── app.json        // 全局配置
├── app.wxss        // 全局样式
├── pages/
│   ├── index/
│   │   ├── index.js      // 页面逻辑
│   │   ├── index.json    // 页面配置
│   │   ├── index.wxml    // 页面结构
│   │   └── index.wxss    // 页面样式
│   └── logs/
├── utils/          // 工具函数
└── project.config.json  // 项目配置
```

**全局配置app.json**
- pages：页面路径列表
- window：全局窗口样式（导航栏、背景色等）
- tabBar：底部标签栏
- permission：权限配置

#### 3. WXML语法（20分钟）

**WXML与HTML的区别**
| 特性 | HTML | WXML |
|------|------|------|
| 标签 | div, span, p等 | view, text, image等 |
| 属性 | class, id, style | class, id, style（小程序特定） |
| 事件 | onclick | bindtap, catchtap |
| 模板 | 无原生支持 | template模板 |
| 列表渲染 | 需JS循环 | wx:for指令 |

**数据绑定**
```xml
<!-- 简单绑定 -->
<view>{{ message }}</view>

<!-- 组件属性绑定 -->
<image src="{{ imgUrl }}"></image>

<!-- 控制属性绑定 -->
<view wx:if="{{ condition }}">显示内容</view>

<!-- 运算 -->
<view>{{ a + b }}</view>
<view>{{ flag ? '是' : '否' }}</view>
```

**列表渲染**
```xml
<!-- 默认 item 和 index -->
<view wx:for="{{ array }}">
  {{ index }}: {{ item }}
</view>

<!-- 指定变量名 -->
<view wx:for="{{ list }}" wx:for-item="itemName" wx:for-index="idx">
  {{ idx }}: {{ itemName.name }}
</view>

<!-- wx:key 提高渲染效率 -->
<view wx:for="{{ users }}" wx:key="id">
  {{ item.name }}
</view>
```

**条件渲染**
```xml
<view wx:if="{{ score >= 90 }}">优秀</view>
<view wx:elif="{{ score >= 60 }}">及格</view>
<view wx:else>不及格</view>
```

**模板与引用**
```xml
<!-- 定义模板 -->
<template name="userCard">
  <view class="card">
    <text>{{ name }}</text>
    <text>{{ age }}</text>
  </view>
</template>

<!-- 使用模板 -->
<template is="userCard" data="{{ name: '张三', age: 20 }}"></template>
```

### 第二学时：样式、生命周期、路由与云开发

#### 4. WXSS与页面生命周期（20分钟）

**WXSS语法特点**
- 新增rpx响应式像素单位（750rpx = 屏幕宽度）
- 支持@import样式导入
- 支持全局样式与局部样式
- 选择器支持：.class、#id、element、::before/::after等

**常用布局方案**
- Flex布局（推荐）
- 传统盒模型
- Grid布局（基础库2.10.0+支持）

```css
/* Flex布局示例 */
.container {
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
}
```

**页面生命周期**
- `onLoad(options)`：页面加载，可获取路由参数（仅触发一次）
- `onShow()`：页面显示/切入前台时触发
- `onReady()`：页面初次渲染完成（仅触发一次）
- `onHide()`：页面隐藏/切入后台时触发
- `onUnload()`：页面卸载时触发

**生命周期执行顺序**
```
页面进入：onLoad → onShow → onReady
页面后退：onHide（navigateTo） → onUnload（redirectTo/navigateBack）
页面再进入：onShow（从后台切回）
```

**生命周期应用场景**
- onLoad：数据初始化、获取路由参数
- onShow：刷新数据、更新状态
- onReady：获取DOM节点信息、动画初始化
- onHide：暂停定时器、停止播放
- onUnload：清理资源、取消请求

#### 5. 页面路由与数据绑定（20分钟）

**路由跳转方式对比**

| 方式 | API | 特点 | 适用场景 |
|------|-----|------|---------|
| 保留当前页 | wx.navigateTo | 可返回，页面栈+1 | 详情页、表单页 |
| 关闭当前页 | wx.redirectTo | 不可返回，页面栈替换 | 登录页、引导页 |
| 切换TabBar | wx.switchTab | 只能跳TabBar页 | 底部导航切换 |
| 关闭所有页 | wx.reLaunch | 清空页面栈 | 首页重置 |
| 返回上一页 | wx.navigateBack | 返回指定层级 | 返回操作 |

**navigateTo 示例**
```javascript
// 跳转并传递参数
wx.navigateTo({
  url: '/pages/detail/detail?id=123&name=test'
})

// 目标页面接收参数
Page({
  onLoad(options) {
    console.log(options.id)   // 123
    console.log(options.name) // test
  }
})
```

**事件处理**
- 绑定方式：bindtap（冒泡）、catchtap（阻止冒泡）
- 事件对象：event.detail、event.currentTarget.dataset

```xml
<!-- 事件绑定 -->
<button bindtap="handleTap">点击我</button>
<button catchtap="handleCatch">阻止冒泡</button>

<!-- 传递参数 -->
<view data-id="{{ item.id }}" bindtap="handleItemTap"></view>
```

```javascript
Page({
  data: {
    count: 0
  },
  handleTap() {
    this.setData({
      count: this.data.count + 1
    })
  },
  handleItemTap(e) {
    const id = e.currentTarget.dataset.id
    console.log('点击了：', id)
  }
})
```

**setData 使用要点**
- 必须通过 setData 修改数据才能触发视图更新
- 支持数据路径修改：`'user.name'`、`'list[0].title'`
- 单次设置数据不超过1024KB
- 避免频繁调用setData影响性能

#### 6. 小程序云开发基础（10分钟）

**云开发概念**
- 微信官方提供的后端云服务
- 无需搭建服务器，免运维
- 三大基础能力：云函数、云数据库、云存储

**云函数**
- 运行在云端的JavaScript函数
- 天然拥有微信调用权限
- 示例：获取用户openid、操作数据库

```javascript
// 云函数示例
exports.main = async (event, context) => {
  return {
    sum: event.a + event.b
  }
}

// 小程序端调用
wx.cloud.callFunction({
  name: 'sum',
  data: { a: 1, b: 2 },
  success: res => console.log(res.result)
})
```

**云数据库**
- JSON文档型数据库
- 集合（Collection）→ 文档（Document）
- 权限控制：所有用户可读、仅创建者可读写等

```javascript
// 查询数据
const db = wx.cloud.database()
db.collection('users').where({
  age: db.command.gt(18)
}).get().then(res => console.log(res.data))
```

## 五、学前测验

### 测验说明
本测验旨在检测学习者对微信小程序前置知识的了解程度，帮助确定学习起点。

### 测验题目

**第1题**：微信小程序使用的开发框架是什么？
A. React Native
B. Flutter
C. MINA
D. UniApp

**正确答案**：C
**答案解释**：MINA是微信小程序官方开发框架，采用双线程架构（视图层+逻辑层），通过数据驱动视图更新。React Native和Flutter是跨平台框架，UniApp是第三方多端框架。

**第2题**：在微信小程序中，用于编写页面结构的文件扩展名是什么？
A. .html
B. .wxml
C. .vue
D. .jsx

**正确答案**：B
**答案解释**：WXML（WeiXin Markup Language）是微信小程序的标记语言，用于描述页面结构。虽然语法类似HTML，但标签和属性有差异，如view替代div，text替代span等。

**第3题**：以下哪种小程序页面跳转方式会保留当前页面，可通过返回按钮回到原页面？
A. wx.redirectTo
B. wx.switchTab
C. wx.navigateTo
D. wx.reLaunch

**正确答案**：C
**答案解释**：wx.navigateTo会保留当前页面并跳转到新页面，页面栈深度最多10层。wx.redirectTo会关闭当前页再跳转，wx.switchTab用于TabBar页面切换，wx.reLaunch会清空所有页面栈。

**第4题**：在小程序中，修改data中的数据并触发视图更新的正确方法是？
A. 直接修改 this.data.xxx
B. this.setData({ xxx: value })
C. this.setState({ xxx: value })
D. this.updateData({ xxx: value })

**正确答案**：B
**答案解释**：小程序必须通过setData方法修改数据才能触发视图更新。直接修改this.data不会触发渲染。setState是React的API，updateData不存在。

**第5题**：微信小程序云开发提供的三大核心能力不包括以下哪项？
A. 云函数
B. 云数据库
C. 云服务器（ECS）
D. 云存储

**正确答案**：C
**答案解释**：小程序云开发提供云函数（Serverless）、云数据库（文档型）、云存储（文件存储）三大能力。云服务器（ECS）是IaaS层服务，需要自己运维，不属于云开发范畴。

### 测验结果评估
