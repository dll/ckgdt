# 版本号与品牌名 — 单一来源（SSOT）完整文档

> **核心原则**：Dart 代码中所有版本号/品牌名只从 `BuildInfo` 读取。
> 升版时只改 `version.dart`，再通过 `scripts/version_bump.dart` 同步到各平台清单。

---

## 一、Dart 代码唯一入口

### `lib/core/version.dart` — 版本号 SSOT

```dart
class Version {
  static const int major = 2;
  static const int minor = 5;
  static const int patch = 3;
  static const int build = 0;
  static const String display = '2.5.3';      // 显示用
  static const String pubspec = '2.5.3+0';    // pubspec 格式
  static const String platform = '2.5.3';     // 平台清单格式
}
```

### `lib/core/build_info.dart` — 品牌名 + 派生值

| 字段 | 值 | 用途 |
|------|------|------|
| `appVersion` | `Version.display` → `'2.5.3'` | 关于对话框、更新检查、检查更新按钮 |
| `appBrand` | `'CKGDT'` | 窗体标题简称、QR JSON、tooltip |
| `appFullName` | `'课程知识图谱与数字孪生平台'` | 关于对话框标题、Agent 上下文 |
| `appEnglishName` | `'Course Knowledge Graph and Digital Twin Platform'` | 关于对话框英文名 |
| `appEdition` | `'EDITION 2026'` | 登录页副标题年份 |
| `appBrandWithVersion` | `'CKGDTv2.5.3'` | 窗体标题（main.dart） |
| `appVersionLine` | `'V2.5.3 · EDITION 2026'` | 登录页副标题 |
| `displayFullName(courseName)` | `'《课程名》课程知识图谱与数字孪生平台'` | 关于对话框、home 页标题 |
| `displayBrandWithVersion(courseName)` | `'《课程名》CKGDTv2.5.3'` | MaterialApp.title |

## 三、升版操作清单

升版时按以下顺序操作（只需改 1 个 Dart 文件 + 1 个命令）：

### 步骤 1：改 `lib/core/version.dart`

```dart
static const int major = 2;
static const int minor = 6;  // ← 改这里
static const int patch = 0;
static const int build = 0;
static const String display = '2.6.0';
static const String pubspec = '2.6.0+0';
static const String platform = '2.6.0';
```

### 步骤 2：运行同步脚本

```bash
dart run scripts/version_bump.dart
```

脚本自动同步以下文件：
- `pubspec.yaml`
- `android/app/src/main/res/values/strings.xml`
- `windows/CMakeLists.txt`
- `windows/runner/main.cpp`
- `windows/runner/Runner.rc`（3 处）
- `web/index.html`（3 处）
- `web/manifest.json`
- `ohos/AppScope/app.json5`

### 步骤 3：验证一致性

```bash
grep -E "version:|app_name|BINARY_OUTPUT_NAME|window\.Create|FileDescription|<title>|versionName" \
  pubspec.yaml \
  android/app/src/main/res/values/strings.xml \
  windows/CMakeLists.txt windows/runner/main.cpp windows/runner/Runner.rc \
  web/index.html \
  ohos/AppScope/app.json5 \
  lib/core/version.dart
```

期望所有版本号对齐到同一个 `X.Y.Z`。

## 五、禁止事项

1. **禁止**在 lib/ 中硬编码版本号字符串（如 `'2.5.3'`）
2. **禁止**在 lib/ 中硬编码品牌名字符串（如 `'CKGDT'`）
3. **禁止**在 lib/ 中硬编码完整产品名（如 `'课程知识图谱与数字孪生平台'`）
4. **禁止**修改 `version.dart` 时不运行 `version_bump.dart` 同步
5. **禁止**在平台清单中手动改版本号（应通过脚本同步）
